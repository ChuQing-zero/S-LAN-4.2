# 硬件说明

本机由**三块自制电路板** + 3D 打印结构件 + 铝型材机架组成。三块板各管一件事，**分别烧不同的固件**，下面这张表是烧录对照。

## 一、三块板与对应固件（★ 最重要）

| 部件（板） | 主控芯片 | **最终固件（就烧这一份）** | 烧录方式 | 关键注意 |
|---|---|---|---|---|
| **进料 / 总控**（FEED 板） | Arduino Nano（ATmega328P） | `固件/01-最终固件/87-ZLocal/87-ZLocal.ino` | Arduino IDE 或 arduino-cli，USB(CH340)，115200 | Flash 30,360 / 30,720 字节（98%）；ESP-01 插在这块板上 |
| **识别单元**（IDEN 板，I²C 地址 **0x10**） | STM32F103C8T6 ×1 | `固件/01-最终固件/57-IdentUnit-FINAL/main.c` | Keil5 编译 + ST-Link 烧录 | 挡片舵机接 PB11（TIM2_CH4）；180° 舵机 |
| **分拣单元**（UNIT 板，I²C 地址 **0x20~0x23**） | STM32F103C8T6 ×4 | `固件/01-最终固件/30-SortUnit-V5/main.c`<br>（同目录 `main_0x20.c`~`main_0x23.c` 是四块板的现成副本） | Keil5 编译 + ST-Link 烧录 | **必须改第 13 行**<br>`#define BOARD_ADDR_7BIT 0x20`<br>四块板分别填 `0x20 / 0x21 / 0x22 / 0x23` |

合计：**5 块 STM32 单元板**（1 识别 + 4 分拣）+ 1 块 Nano 主控。

```c

```

## 四、I²C 总线（最容易接错的地方）

**SDA / SCL 各接一个上拉电阻到 VCC，不是下拉。** 本项目做法：

- 阻值 **2.2 kΩ × 2**，**统一做在主机（Nano）那一端**，各个单元板**一律不加**
  （多板并联会让阻值变小、灌电流变大）
- 上拉到 **5V**：STM32 的 PB6/PB7 数据手册标 `FT`（5V 容忍），可直接挂 5V 总线，**不需要电平转换芯片**
- 速率 **50kHz**（为稳定特意降速，不是 100kHz）

接错的现象与排查：

| 现象 | 原因 |
|---|---|
| 总线恒定低、扫不到从机 | 接成了**下拉**（连到 GND） |
| 偶发扫不到、极不稳 | **忘了上拉**，总线浮空 |
| 某些板子读不到 | 每块单元板都加了上拉，阻值过小 |
| 完全不通 | 电阻串在了信号线中间 |

排查：断电测 SDA↔5V、SCL↔5V 应各 2.2kΩ；通电不接从机时两根线对 GND 应 4.8~5.0V（量到 0V 就是接成下拉了）。

> 注意：Arduino 内部上拉只有 20~50kΩ，太弱，长线多从机时会上升沿变慢、偶发丢包，**必须外挂 2.2kΩ**。

## 五、关键接线与地址

| 项目 | 值 |
|---|---|
| I²C 主站 | Nano A4(SDA) / A5(SCL) |
| 从机地址 | 识别 `0x10`、分拣 `0x20 / 0x21 / 0x22 / 0x23` |
| 进料电机（L298N） | ENA=D7、IN1=D8、IN2=D9 |
| 继电器 | 风扇 A1、补光灯 A2（`RELAY_ON = HIGH`） |
| 进料口光敏 | Nano A7 |
| 单元光敏 | STM32 PA0 → ADC1 通道 0 |
| 挡片舵机 | 识别单元 PB11 / TIM2_CH4 |
| 分拣双舵机 | 单单元两只 360° 持续旋转舵机 + 限位开关 |

## 六、结构件

- 机架：2020 / 2040 铝型材（2020 作立柱、2040 作横梁），角件连接、位置可微调
- 3D 打印：拓竹 A1，PLA、填充 15~25%
- 输送：Ø4 mm PU 圆皮带（热接成环）套 Ø30 mm 打印滚筒，两滚筒中心距约 60 mm
- 分拣：每口两只 360° 舵机 + 齿轮齿条 + 限位开关，装在一个打印的「舵机限位机构盒」里
- 矫正：喇叭形限位片由宽到窄收拢，中间挡板先把斜的卡扶平，放行后自动居中

## 七、ESP-01 供电（踩过很久的坑）

ESP8266 射频发射瞬间峰值 **170~350 mA、持续约 1 ms**，供电不足会反复复位、掉线、`no ip`。

- **绝不能从 Nano 的 3.3V 脚取电**（那里只有约 150mA）
- 用独立 3.3V 稳压（AMS1117-3.3 或 500mA 以上的降压模块）
- 模块引脚旁加**三级滤波**：

| 级 | 规格 | 封装 |
|---|---|---|
| 储峰 | 470 µF / 16V 贴片铝电解 | 6.3×7.7 mm |
| 中频 | 22 µF / 16V 陶瓷（X5R） | 1206 |
| 高频 | 100 nF / 50V 陶瓷（X7R） | 0603 |

布局：`0.1µF` 离模块引脚最近（≤5mm），其次 22µF，470µF 可稍远，整段走线 ≤5cm，地线要粗要短。

> 电容只能削峰，**源头必须能持续输出 350mA**。另外 ESP-01 没有复位脚，卡死只能整板断电 5 秒。
