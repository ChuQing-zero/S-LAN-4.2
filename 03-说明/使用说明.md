# 使用说明（整机怎么跑一遍）

## 一、开机前检查（5 项，缺一项都跑不起来）

```
□ 数据库 28018、后端 4002、设备端 6001 三个服务都起来了
□ Nano 已接 USB（或 WiFi 已连上 ESP-01），设备端 /status 里能看到链路
□ 拍照手机 ADB 在线（`adb devices` 能看到序列号）
□ 皮带与各光敏上没有残留卡牌（有卡会拒绝启动）
□ 料仓里有卡，卡牌方向放对
```

启动前系统会**自动自检 5 路光敏**：某一路被遮会拒绝启动并说明是哪一路。偶发读不到（无信号）只告警不拦。

## 二、一次完整的自动流程

点「开始运转」后，先做启动准备，再逐张循环：

```
启动准备：补光灯开 → 挡片立起 120° → 皮带 150 起转 → 六路光敏实测校准

每一张卡：
 ① 进料：推一张（本地光敏闭环，卡到位置自动停）
 ② 等卡到识别位：0x10 光敏变暗 → 停带 → 静置
 ③ 识别：NFC / 扫码 / 图像（按当前识别方式）
 ④ 放行：挡片放 90° + 皮带起转 → 等卡尾过（0x10 重新变亮）→ 停带 = 拍照位
 ⑤ 拍照：手机快门 → 取回原图 → 缩到宽 720 → 送人工智能识别（3~6 秒）
 ⑥ 规则匹配：按卡牌类别 / 星数 / 编号命中出口 1#~8#
 ⑦ 送卡到口：盯着目标口那一路光敏，卡到头再延时停带
 ⑧ 分拣：写 A/B 两路舵机时长 → 抬升 → 保持 → 归位（卡靠斜面自重滑落）
 ⑨ 间隔片刻 → 下一张
```

**兜底 = 出口 9**（不是 8）：识别全失败或没命中任何规则时，皮带一直往后把卡送走，**不做任何舵机动作**，不会卡在机器里。

## 三、关键参数（都能在页面改）

| 参数 | 默认 | 作用 |
|---|---|---|
| 皮带 PWM | 150 | 皮带速度（实测 100 带不动，150 才稳） |
| 挡片角度 | 挡住 120° / 放行 90° | 挡住角度变小会挡不住卡 |
| 识别位停带延时 | 500 ms | 光敏变暗后再等多久停带（决定停在哪） |
| 拍照位停带延时 | 0 ms | 卡尾过光敏后再等多久停带 |
| 分拣口停带延时 | 500 ms | 卡到分拣口变亮后再等多久停带 |
| 舵机抬升保持 | 1000 ms | 抬起来保持多久再归位（要留给卡滑落） |
| 每张间隔 | 5000 ms | 跑完一张等多久再跑下一张 |
| 兜底传送 | 30000 ms | 出口 9 送走时间 |

四个流程开关：`启动校准` / `拍照前对焦` / `拍照期间暂停投屏` / `分拣口本地停带`。

## 四、8 个出口的舵机参数（现场调定，别乱改）

| 出口 | 单元 | A(ms) | B(ms) |
|---|---|---|---|
| 1# 左 | 0x20 | 400 | 800 |
| 2# 右 | 0x20 | 800 | 400 |
| 3# 左 | 0x21 | 500 | 900 |
| 4# 右 | 0x21 | 900 | 500 |
| 5# 左 | 0x22 | 500 | 900 |
| 6# 右 | 0x22 | 900 | 500 |
| 7# 左 | 0x23 | 500 | 900 |
| 8# 右 | 0x23 | 900 | 500 |

**两个出口共用一个单元、单元里只存一对 A/B**，所以每次换口都必须**先写参数再抬升**；参数写丢会表现为「这一口抬起来左右一样高」。

## 五、分拣规则（当前 9 条）

| 出口 | 规则 |
|---|---|
| 1# 左 | 融合 / 同调 / 超量 / 连接怪兽 |
| 2# 右 | 通常 / 效果怪兽 **且** 星数 ≥5 |
| 3# 左 | 通常 / 效果怪兽 **且** 星数 ≤4 |
| 4# 右 | 魔法卡 |
| 5# 左 | 陷阱卡 |
| 6# 右 | 仪式怪兽 |
| 7# 左 | 灵摆怪兽 |
| 8# 右 | 衍生物 |
| 9# | 兜底：没识别到就送走，不做舵机动作 |

规则按 1#→8# 顺序逐条匹配，**第一条命中的就是出口**，所以"怪兽≥5 星"这类条件必须排在"怪兽"前面，别手动打乱顺序。

## 六、实测节拍（可作为参考基线）

| 项目 | 数据 |
|---|---|
| 连续 3 张平均 | **32.2 秒/张**（3 张 96.7 秒，3/3 分类正确） |
| 单张（含档片升降与舵机复位） | 约 42.8 秒 |
| 其中拍照 + 人工智能 | 拍照约 7 秒、识别 3~6 秒 |
| 送卡到出口 | 8.8~19 秒（看出口远近：3#/5# 近，1#/7#/8# 远） |
| 抬升 + 保持 + 复位 | 约 2 秒（原来要十几秒，是等回执造成的，已优化） |

## 七、常见故障速查

| 现象 | 最可能的原因 |
|---|---|
| 点了开始就退回空闲 | 有光敏被残留卡遮住；或手机 ADB 不在线 |
| 卡推出来但走不到识别位 | 皮带没转（每张开头必须重设皮带与挡片） |
| 识别位冲过头 / 停太早 | 识别位停带延时或光敏阈值不合适 |
| 拍照失败 → 走出口 9 | 手机相机在录像模式 / 不在前台 / ADB 掉线 |
| 分拣口卡几十秒 | `[Z] STOP` 回包丢失，靠状态位 bit6 兜底；若仍超时查无线质量 |
| 舵机抬升左右一样高 | 换口时 A/B 参数没写成功（丢包），会重试 3 次并告警 |
| 整机不动、指令无回显 | 先看设备端 `link.wifi` 的收发计数：tx 涨 rx 不涨 = 收不到，整板断电 5 秒 |

## 八、日常维护

- **换网络**：ESP-01 固件里的静态 IP 是写死的，换网段必须改 `ESP_IP` 与固件宏，否则无线永远连不上
- **换手机**：改 `PHONE_SERIAL` 与 `PHONE_ADB`，并在手机端重新开一次 `adb tcpip 5555`
- **断电后**：进料阈值、挡片角度、A/B 参数都是掉电丢失的，靠「开始运转」时的自动校准与参数下发恢复
- **动过参数后**：先单张跑一遍确认，再切连续模式
