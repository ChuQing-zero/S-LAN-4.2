# 软件说明

上位机由三部分组成：**Server**（Node 后端 + 静态页面托管）、**Client**（uni-app 前端源码）、**Device**（Python 设备端，直接跟 Nano 说话）。

## 一、目录

```
02-软件/
├─ Server/          后端 Node（Express + Mongoose）  端口 4002
│  ├─ src/index.js          入口
│  ├─ src/routes/           各业务路由（device.js 是设备代理）
│  └─ .env.example          环境变量样例（复制成 .env 再填）
├─ Client/          前端 uni-app 源码（Vue3 + uni-app）
│  ├─ src/pages/            页面（设备调试 / 设备连接2 等）
│  ├─ src/api/              接口封装
│  └─ .env.example
└─ Device/          设备端 Python（Flask）          端口 6001
   ├─ app.py                所有 /xxx 接口
   ├─ main_flow.py          整机主流程（唯一一套）
   ├─ link_wifi.py          ESP-01 无线长连接
   ├─ phone_link.py         拍照手机 ADB 发现与连接
   ├─ feed_seq.py / speed_stop.py / ldr_probe.py / feed_auto.py   单模块调试工具
   ├─ sort_rules.py         分拣规则引擎
   └─ config.json           全部可调参数（★ 已脱敏，见第四节）
```

## 三、启动顺序

```bash
# ① 数据库（自己装 MongoDB 或用便携版，端口 28018）
mongod --dbpath <你的数据目录> --port 28018

# ② 后端
cd 02-软件/Server
npm install
node src/index.js            # 看到监听 4002 即成功

# ③ 设备端
cd 02-软件/Device
python app.py                # 看到监听 6001 即成功

# ④ 打开浏览器
http://localhost:4002
```

前端修改后要重新编译（`npm run build:h5`），产物在 `Client/dist`，由 Server 托管。
**`Client/dist` 不在仓库里**，需要自己 build。

## 四★、`Device/config.json` 必须按现场改（已脱敏）

仓库里的值都是**占位值**，直接跑会连不上设备：

| 键 | 仓库里的值 | 你要改成 |
|---|---|---|
| `ESP_IP` | `192.168.1.100` | 你板子上 ESP-01 的实际 IP |
| `ESP_PORT` | `8080` | 一般不改 |
| `PHONE_ADB` | `192.168.1.50:5555` | 拍照手机的无线 adb 端点 |
| `PHONE_SERIAL` | `YOUR_PHONE_SERIAL` | 手机 `adb devices` 看到的序列号 |
| `ADB_PATH` | `adb` | 你的 adb.exe 路径（在 PATH 里就写 adb） |
| `SAVE_DIR` | `./Storage/photos` | 照片落盘目录 |

其余是工艺参数（阈值、延时、PWM、八路口 A/B 毫秒数、分拣规则），一般不用动。

**新增可保存参数时注意**：新键必须同时加进 `app.py` 的 `CONFIG_DEFAULTS` 和 `BOOL_FIELDS`，否则保存接口会静默丢弃。

## 五、豆包（火山方舟）Key 怎么填

本仓库**不含任何 Key**。图像识别需要你自己申请：

```
① 到火山方舟控制台申请 API Key
② 模型选 doubao-seed-2-0-mini-260428
③ 打开系统 → 管理后台 → API Key → 新增一条，把 Key 粘进去
④ 设为默认，图像识别才会用它
```

调用走 Responses API：`https://ark.cn-beijing.volces.com/api/v3/responses`，
请求头 `Authorization: Bearer <你的Key>`，图片以 `input_image` 传入。

> Key 只存数据库，不写进代码，也不会进这个仓库。

## 六、接口分层（改代码时别漏）

设备端加一个新接口要改**三处**，缺一处就是 404：

1. `Device/app.py` —— 真正实现（Flask，重启 python 生效）
2. `Server/src/routes/device.js` —— 代理 + 鉴权（**必须重启 node**）
3. `Client/src/api/*.js` + 页面 —— 前端调用

自检：不带 token 请求 `http://127.0.0.1:4002/v1/api/device/<新路由>`
返回 **401** = 路由在；返回 **404** = node 没重启。

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 启动报 `EADDRINUSE :::4002` | 已有实例在跑，旧实例仍在服务；要换新代码先停旧的 |
| 前端页面没变化 | 没 `npm run build:h5`，或浏览器没强刷（Ctrl+Shift+R） |
| 设备端连不上 Nano | 串口被 Arduino IDE 的串口监视器占用（先关掉）；或 COM 口填错 |
| 无线链路连不上 | 电脑与 ESP 不在同一网段（换 WiFi 后 IP 变了） |
| 手机投屏黑屏 | 相机 App 在前台（系统禁止截屏），先回桌面 |
| 手机拍不出照片 | 相机停在录像模式（相册里全是 `VID_*.mp4`），先切回拍照 |
| 舵机不动 / 抬升一样高 | 两个出口共用一个单元，抬升前必须先写 `P,au` + `P,bu` 再 `S,raise` |

## 八、README 里没写但要知道的三条铁律

1. **V1.2 的 PC 代码不要动** —— 现在这套是 V1.3 开发副本，端口全部 +1000 隔离
2. **改完必须重启/重编译**：py 改完重启 6001、js 改完重启 4002、前端改完 build、固件改完重烧
3. **参数校验看回读值**，不要只看"保存成功"——保存接口有白名单与布尔字段名单，会静默丢键
