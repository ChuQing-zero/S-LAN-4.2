  TCG 卡牌扫描 · 网页拍照控制台 —— 使用说明
════════════════════════════════════════════════

【功能】
  · 左半边：手机实时画面（约 1~2 帧/秒）
  · 右半边：立即拍照 / 当前计数 / 状态灯 / 串口日志 / 已保存照片
  · 自动拍照：卡成功通过光敏 1 秒后，自动截屏存到 photos 文件夹
  · 状态灯：Arduino 每 0.1 秒广播状态，网页实时显示：
       绿色 待命（正常运行中）   黄色 等待卡
       红色 报警中 / 遮挡报警    灰色 已停止
      报警/遮挡时：状态灯红闪 + 电脑"嘀"一声 + 日志里有记录
  · 参数调节：网页右下角直接改参数，点"保存参数"→ 存到 config.json
     （改 COM 端口/波特率会自动重连串口，不用重启程序）

【第一次使用前准备】
  1. 手机插 USB 线连电脑，开好 USB 调试（开发者选项里）。
  2. 打开电脑的 cmd 或终端，输入：  adb devices
     看到你的设备编号即成功。第一次会弹"允许USB调试"授权框，点允许。
  3. 打开手机相机 App，把摄像头对准卡牌要经过的位置，停在取景画面。

【运行】
  1. 先关闭 Arduino IDE 的串口监视器（本程序要独占串口）。
  2. 打开终端，进入本文件夹：
       cd "D:\Project\S-LAN\Build\Fully automatic TCG card scanner\拍照控制台"
       python app.py
  3. 浏览器打开：  http://localhost:5000

【使用】
  · 网页左边就是手机实时画面；调整手机位置直到对准卡牌。
  · 点"📷 立即拍照" → 手动截一张，存到 photos 文件夹。
  · 点"📍 点击对焦" → 在手机屏幕中心点一下，触发相机对焦（不拍照）。
  · 拍照前默认会自动点一下屏幕中心对焦（见下方"拍照前对焦"参数），
    等 0.6 秒对焦稳定后才截屏。
  · 正常扫描：按 D6/发 c 推卡，卡通过光敏 → 计数 +1 → 1 秒后自动拍照。
  · 照片点开可看大图，都在 photos 文件夹里。

【网页改参数】
  · COM 端口：AUTO=自动识别，找不到就写 "COM3" 这样
  · 波特率：默认 9600（Arduino 里 Serial.begin(9600) 一样）
  · 画面刷新(秒)：越小越流畅但手机费电，默认 0.3
  · 拍照延迟(秒)：卡通过后等几秒再拍，默认 1.0
  · 日志条数：网页日志最多保留多少条，默认 60
  · 拍照前对焦：勾选 = 每次拍照前自动点屏幕中心触发对焦（默认勾选）
  · 对焦X/Y(%)：对焦点位置，50=屏幕正中间，可按卡牌位置调整
    （比如卡牌偏左就改 X=30，偏上就改 Y=35）
  · 改完点"💾 保存参数"，立即生效并写进 config.json，
    下次启动程序自动读取。

【常见问题】
  · 网页显示"暂无画面" → 手机没连上，检查 USB 线和授权框。
  · 串口显示"未找到 Arduino" → 检查 USB、或 Arduino IDE 监视器没关。
  · 计数显示 "-" → 还没读到串口；连上后按一次 D6 推卡就有了。
  · 状态灯一直灰色"已停止" → 没收到 Arduino 状态广播，检查串口连接。
  · 5000 端口被占用 → 改 app.py 里的 port 数字（如 6001）。
