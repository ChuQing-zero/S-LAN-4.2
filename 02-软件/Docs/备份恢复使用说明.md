# 使用说明 — 备份与恢复

> 本文档教你如何备份数据库、恢复数据库。
> 备份 = 把当前全部数据打包存一份（不会影响正在运行的系统）。
> 恢复 = 用某次备份覆盖当前数据（会把现在的数据换成备份时的样子）。

---

## 一、什么时候该备份

| 场景 | 建议 |
|------|------|
| 每天收工前 | 备份一次 |
| 要做大改动/清空数据前 | 必须先备份 |
| 定期（如每周） | 备份一次更保险 |

**备份很快，10 秒内完成，随时可以点。**

---

## 二、怎么备份（双击一个文件）

1. 打开文件夹：`D:\Project\S-LAN\Code\V1.1\Deploy`
2. **双击 `backup.bat`**（中文名：备份）
3. 等它跑完（显示 `full backup done [OK]`）
4. 按回车关掉窗口，完成

### 备份存在哪

```
D:\Project\S-LAN\Code\V1.1\Storage\backup\
└── 20260818-101413\          ← 每次一个文件夹，名字=年月日时分秒
    ├── mongodump\            ← 数据库完整备份（最重要的东西）
    ├── config\               ← 后端配置文件
    └── env-backup.txt        ← 密钥配置
```

- 每次备份**不会覆盖**以前的，各存各的
- 备份多了占空间，可以手动删除很旧的不需要的文件夹

---

## 三、怎么恢复（双击另一个文件）

1. 打开 `D:\Project\S-LAN\Code\V1.1\Deploy`
2. **双击 `restore.bat`**（中文名：恢复）
3. 窗口会列出所有历史备份，例如：

```
  Available backups:
  [1] 20260818-101413  (10.5 MB)
  [2] 20260817-223000  (10.4 MB)
```

4. 输入你想恢复的那份的**编号**（比如 `1`），回车
5. 它会让你输入 `YES` 确认（防止误操作）
6. 等恢复完成，显示 `Restore done [OK]`

> ⚠️ **注意**：恢复会把当前数据库**整体替换**成备份时的状态。恢复之后新产生的数据会消失。确认要恢复再输 YES。

---

## 四、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 备份报错 `mongodump failed` | MongoDB 没在运行 | 先双击 `start.bat` 启动系统 |
| 恢复列表为空 | 从没备份过 | 先备份 |
| 恢复报错 | 备份文件夹被手动改过 | 用没动过的备份文件夹 |
| 想删掉旧备份 | 占空间 | 直接删除 `backup` 里对应的日期文件夹即可 |
