# 整机测试（限位 + 光敏 + 4 颗灯，不含通信）

S-LAN V4.0 / **STM32F103C8T6 蓝 pill**
纯寄存器 · 不用 CubeMX · 不用 HAL
日期：2026-09-22

> **一句话**：把**除板间通信（I²C）以外**的所有东西合到一个程序里跑起来 ——
> 限位开关 → 限位灯，光敏 → 卡牌灯，四颗灯**同时**工作。
>
> ```
>   限位开关 1（PB9）  ──>  灯 1（PB14）
>   限位开关 2（PB5）  ──>  灯 2（PB15）
>   光敏电阻（PA0）   ──>  灯 3（PA11）      卡牌检测
>   ──                ──>  灯 4（PA12）      1Hz 心跳（暂时）
>   ──                ──>  板载灯（PC13）    程序还活着的标志
> ```
>
> **主要目的是两件事：**
> **① 把光敏阈值量出来**（这个数到现在还没定）**② 证明四颗灯能一起工作**。

---

## 一、这一步为什么单独做

前面每个测试都是**一次只验一件事**：

| 测试 | 验了什么 | **没验什么** |
|---|---|---|
| `04` | 能不能读到限位开关 | 没接灯 |
| `05` | 光敏 ADC 能不能读 | **阈值一直没定** |
| `06` | 限位 → 灯（**只有 2 颗**）| 光敏不在里面 |
| `07` | 四颗灯**一颗一颗**点名 | 不是同时，也没有输入 |

**这一步把上面四份合起来**，并且是第一次让四颗灯**同时**由真实输入驱动 ——
这和"一颗一颗点名"是**两回事**，出问题的方式也不一样（比如两颗灯抢同一个端口）。

---

## 二、四颗灯分别是哪四颗

| 编号 | 引脚 | 脚号 | 右排位置 | 亮的时候表示 |
|---|---|---|---|---|
| **1** | **PB14** | 27 | 从下往上第 3 根 | 限位 1 触发 |
| **2** | **PB15** | 28 | 从下往上第 4 根 | 限位 2 触发 |
| **3** | **PA11** | 32 | A9 上面第 1 根 | **光被挡住 = 检测到卡** |
| **4** | **PA12** | 33 | A9 上面第 2 根 | 1Hz 闪，心跳 |

> ```
>       A12   ← 灯 4（心跳）
>       A11   ← 灯 3（卡牌检测）
>       A10   串口
>       A9    串口
>       A8    ✂ 空着
>       B15   ← 灯 2（限位 2）
>       B14   ← 灯 1（限位 1）
>       B13   ← 限位开关 2 的 COM
>       B12   ← 限位开关 1 的 COM
> ```
>
> ⭐ **和 `01-单元板方案.md` §5.6 的 PCB 分配完全一致** —— 这份程序可以直接照搬到板子上。

## 三、接线

### ① 两个限位开关（4 根）

```
   限位开关 1                       蓝pill
   ┌────────┐
   │ COM ●──┼──────────────>  PB9    ← 右排丝印 "B9"（脚 46）
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘

   限位开关 2                       蓝pill
   ┌────────┐
   │ COM ●──┼──────────────>  PB5    ← 右排丝印 "B5"（脚 41）
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘
```

> ⚠️ **两根针都在右排上半部分**（B9 从上数第 4 根，B5 第 8 根），
> 不再是以前的 PB12 / PB13（右排最底下）。
>
> ⚠️ **PB5 不 5V 耐受**（脚 41），别往它上面接 5V。

**用 COM + NC（常闭）不是 NO** —— 这样**线断了 = 读到"已触发" = 安全停机**。

### ② 四颗指示灯（8 根）

**四颗接法完全一样**，只是引脚不同：

```
   PB14 ──[ 470Ω ]── LED1 长脚（正极）
                      LED1 短脚（负极）──> GND

   PB15 ──[ 470Ω ]── LED2 长脚          LED2 短脚 ──> GND

   PA11 ──[ 470Ω ]── LED3 长脚          LED3 短脚 ──> GND

   PA12 ──[ 470Ω ]── LED4 长脚          LED4 短脚 ──> GND
```

> **长脚 = 正极**，接电阻那一头；**短脚 = 负极**，接 GND。
> 四颗都是**高电平亮**，和板载 PC13 **正好相反**。
>
> ⚠️ **电阻夹在「引脚」和「LED 长脚」之间**，不能和 LED 插在同一排
> （同一排 5 个孔是连通的，会被短路）。

### ③ 光敏电阻（3 根）

```
   +3V3 ──[ 光敏 GL5528 ]──┬──[ 10kΩ ]── GND
                            │
                            └──> PA0（脚 10）
```

> ⚠️ **必须是 +3V3，不能是 +5V** —— PA0 **不 5V 耐受**，接 5V 会烧引脚。
>
> ⭐ **这一步暂时不接光源 LED**，用环境光就行 —— 见下面「自然光只是临时的」。

### ④ 串口（3 根）

```
   CH340 TXD ──> PA10        RXD ──> PA9        GND ──> GND        VCC 不接
```

### ⚠️ 舵机**先不要接**

PB10 / PB11 上的两个舵机**这一步故意不接** —— 一次只动一样东西。
跑完这一步再插舵机，进下一版。

## 五、应该看到什么

```
① 上电：板载灯（PC13）慢闪 3 下              = 程序在跑

② 串口立刻出现
     =====================================================
       S-LAN V4.0   system test (no I2C, no servos)
          switch 1 PB9   ->  lamp 1 PB14
          switch 2 PB5   ->  lamp 2 PB15
          light    PA0   ->  lamp 3 PA11   card detect
          --             ->  lamp 4 PA12   1 Hz heartbeat
       clock: PLL, 72 MHz - good
       TH=2000 IS A PLACEHOLDER - ...
     =====================================================

③ 之后每 200ms 刷一行
     SW1=0 SW2=0  ADC= 3421  min=  186 max= 3462  TH= 2000  N=  0  [ clear   ]
```

**然后动手试：**

| 操作 | 灯 1 | 灯 2 | 灯 3 | 灯 4 | 串口 |
|---|---|---|---|---|---|
| 什么都不动 | 灭 | 灭 | 灭 | 1Hz 闪 | `SW1=0 SW2=0 ... [ clear ]` |
| **按住限位 1** | **亮** | 灭 | 灭 | 1Hz 闪 | `SW1=1` |
| **按住限位 2** | 灭 | **亮** | 灭 | 1Hz 闪 | `SW2=1` |
| **挡住光敏** | 灭 | 灭 | **亮** | 1Hz 闪 | `[ BLOCKED ]`，N 加 1 |
| 全做一遍 | **亮** | **亮** | **亮** | 1Hz 闪 | `SW1=1 SW2=1 ... [ BLOCKED ]` |

**四颗灯同时亮** —— 这是 `07` 从来没验过的状态。

### ⭐ 再验一次"断线保护"

**把限位开关 NC 那根线从面包板上拔掉** → 对应的限位灯应该**常亮**，串口变 `SW1=1`。

这是设计要的效果：**线断了 = 当成"已触发" = 安全停机**，而不是继续冲撞机构。

## 六、⭐ 核心步骤：把阈值量出来

**这是这一步存在的主要理由。** `TH=2000` 是从 `05` 抄过来的**占位值**，
**从来没在你的分压上量过** —— 所以在改掉它之前，**灯 3 判断错了是正常的**。

```
① 反复遮挡 / 移开光敏电阻 20 次，盯着串口

② 记下两个数：
      max = ______    ← 不挡的时候（光进得去）
      min = ______    ← 挡住的时候

③ 阈值 = (min + max) ÷ 2 = ______

④ 改 main.c 顶部那一行：
      #define THRESHOLD        2000        ← 改成上面那个数
   F7 重新编译，F8 下载

⑤ 再遮 20 次，N 应该正好是 20，灯 3 每次都跟着亮灭
```

### 判读

| 现象 | 结论 |
|---|---|
| **min 和 max 差得很大**（比如 186 / 3462）| ✅ 很健康，阈值随便取中间都行 |
| **差得不多**（比如 1800 / 2400）| ⚠️ 区分度不够 → 见下面 |
| **N 跑得比实际次数多** | 阈值定得太靠近某一边，光线抖一下就翻 → 往中间挪 |
| **灯 3 常亮或常灭** | 阈值定错了，或者光敏那一路没接好 |

### 区分度不够怎么办（按顺序试）

| # | 怎么做 |
|---|---|
| 1 | 加个**遮光筒**（黑色热缩管）套住光敏，把环境光挡掉 —— **最有效** |
| 2 | 把遮挡的物体**贴近**光敏电阻，别隔空晃 |
| 3 | 把 10kΩ 换成 20kΩ 或 4.7kΩ，找最灵敏的点 |
| 4 | 装上**光源 LED**（见下），光照可控之后区分度会好得多 |

## 七、⚠️ 自然光只是临时的

这一步**故意没接光源 LED**，用环境光。**这对"量阈值"和"验逻辑"是够用的**，
但**它不是设计**：

| | 现在（环境光）| 正式版（光源 LED）|
|---|---|---|
| 光照 | 房间的灯、窗外、影子 | **5mm 白光/绿光 LED，+5V 串 220Ω**，装在机构上（J9）|
| 稳定吗 | ❌ 白天晚上不一样，人走过都有影响 | ✅ 恒定，和机构一起动 |
| 量出来的阈值 | **会漂，以后要重标** | 可以写进文档定稿 |

**为什么正式版必须有光源**：机构自己会挡光，环境光还会变。
靠环境光的阈值，换个房间就误判。

> **所以：这一步量出来的阈值，等光源 LED 装到机构上之后必须再量一次。**

## 八、这一步**没有**做什么

| 没做 | 为什么 | 什么时候做 |
|---|---|---|
| **舵机**（PB10 / PB11）| 一次只动一样东西 | **下一版**，做"舵机转到顶到限位就停"的闭环 |
| **I²C 从机**（PB6 / PB7）| 你说先放着 | 阶段 5 |
| 灯 4 当真正的**通信灯** | 通信还没通，先当心跳用 | I²C 通了之后改 |

> ⭐ **下一版才是重点**：舵机 + 限位的闭环。那是**唯一有硬件损坏风险**的一步
> —— 不做闭环保护，舵机会把机构顶坏。也是论文里"闭环停机"那一条。

## 九、排查

| 现象 | 原因 |
|---|---|
| **上电没有慢闪 3 下** | 程序没跑 → 按复位键 / 查 BOOT0 / 勾 `Reset and Run` / Flash 算法没加 |
| **四颗灯都不亮，但串口正常** | 灯的线插错排了 —— 灯全在**右排** |
| **某颗灯不亮，其他正常** | 那颗 LED / 那个 470Ω / 那 2 根线 → 见 `../07-LedChaseTest/README.md` 的 8 条排查表 |
| ⭐ **某个灯时亮时不亮 / 插上去不亮** | **杜邦线或面包板接触不良** —— 先拔出来重插到底，再怀疑别的 |
| **灯 3 一直亮着或一直灭** | **阈值不对** → 回第六节重量 |
| ⭐ **不按开关对应的灯就常亮** | ① NC 那根没接到 GND ② 开关认错脚接到了 NO ③ **线掉了** —— 注意到没有：**这三条的现象完全一样**，而第 ③ 条是设计要的 fail-safe |
| **ADC 一直是 0** | PA0 没接 / 光敏那一路上电没通 / 分压电阻没插 |
| **ADC 一直是 4095** | 光敏电阻短路了，或者 10kΩ 没接到 GND |
| **ADC 跳得厉害** | 环境光在闪（日光灯 50Hz）→ 加遮光筒 |
| **串口一个字都没有** | ① **TXD/RXD 接反** ② CH340 的 GND 没接 ③ 波特率不是 115200 |
| **串口全是乱码** | 看开机那行是不是 `NOT PLL` —— 晶振没起振 |

### ⭐ 一次踩过的坑，记下来

搭这一步的时候 **PB14 上的灯点不亮**，一度怀疑是芯片引脚坏了，还把灯 1 挪到
PA8 去绕。**最后发现是板子/线没插紧。**

| 教训 | |
|---|---|
| **上拉输入悬空 = 读到 1** | 所以"灯常亮、按了没反应"和"某颗灯不亮"**都可能只是接触不良** |
| **fail-safe 的反面** | 断线被读成"已触发"是**设计要的**，但也意味着**接触不良会伪装成正常触发** |
| **先怀疑接触，再怀疑器件** | 拔出来重插的成本是 5 秒，换一颗灯的成本是 5 分钟 |
