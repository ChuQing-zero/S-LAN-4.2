## 状态机

```
PH_IDLE ──f──> PH_LIFT ──时长到──> PH_HOLD ──保持到──> PH_LOWER ──两限位都闭──> PH_IDLE
                  │                                        │
                  │                                        └──3 秒超时──> PH_FAULT
                  └── 光敏触发（ARM 模式）走同一条路径 ──────┘
```

| 相位 | 值 | 含义 |
|---|---|---|
| `PH_IDLE` | 0 | 空闲 |
| `PH_LIFT` | 1 | 抬升中 |
| `PH_HOLD` | 2 | 保持中 |
| `PH_LOWER` | 3 | 归位中 |
| `PH_FAULT` | 4 | 故障（超时） |

## 上机测试顺序（重要）

**① 先把转速调慢、时间调短**

```
k 0x20 30          ← 转速 300µs，最慢
m 0x20 20 10       ← 舵机1 0.2 秒、舵机2 0.1 秒
```

**② 单路测试，一次一条**

```
1 0x20    舵机1 正转
2 0x20    舵机1 反转
3 0x20    舵机2 正转
4 0x20    舵机2 反转
```

每发一条，看**是哪个舵机在动、往哪个方向**。

**③ 验限位**

用手按限位开关，敲：

```
i 0x20
```

看 `LIMIT=0x?` 的 bit0 / bit1 会不会变。

**④ 两路测试**

```
7 0x20    两路抬升（一高一低靠时间差）
8 0x20    两路下降
9 0x20    归位（碰限位自动停）
```

**⑤ 一键分拣**

```
f 0x20
```

应该：抬升 → 保持 1 秒 → 自动归位 → 完成。

敲 `n 0x20` 看计数 +1。

**⑥ 光敏自动**

```
e 0x20    开
（用手挡光敏）
q 0x20    关
```

遮挡后会自动做一次完整分拣。

## 已知限制

1. **`m` 命令的第二个数值解析可能有坑**——如果 `m 0x20 100 50` 只改了第一个，单独发 `m 0x20 50` 再设一个。
2. **本固件未编译验证**（本机没有 Keil），首次 `F7` 可能报错，报错发我。
3. **限位与舵机的配对是假设的**：PB5 ↔ 舵机1、PB9 ↔ 舵机2。如果实测反了，改 `motion_tick()` 里 `PH_LOWER` 段的 bit 判断即可。
4. **光敏阈值 2000 是估的**，上机后按实测的亮/暗值改寄存器 `0x19`。
