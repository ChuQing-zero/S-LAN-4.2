## 寄存器速查

### 参数区（主控写）

| 地址 | 名称 | 默认 | 说明 |
|---|---|---|---|
| `0x10` | BELT_PWM | 150 | 皮带速度 |
| `0x11` | BELT_DIR | 1 | 皮带方向 |
| `0x12` | GATE_REST_DEG | **90** | 舵机静止/放行角度 |
| `0x13` | GATE_BLOCK_DEG | **20** | 舵机挡住角度 |
| `0x14` | GATE_MS | 30 | 舵机转动时间（×10ms） |
| `0x15` | SCAN_TIMEOUT | 30 | 扫码超时（×100ms = 3 秒） |
| `0x16` | NFC_TIMEOUT | 20 | NFC 超时（未用） |
| `0x17` | BLOCK_MS | 100 | 光敏判定 |
| `0x18` | **LED_MASK** | 0 | 点亮 0~4 颗灯 |

### 读回区（主控读）

| 地址 | 名称 | 说明 |
|---|---|---|
| `0x20`/`0x21` | ADC_L/H | 光敏 |
| `0x22` | CARD | bit0 = 有卡遮挡 |
| `0x23` | RES_TYPE | 0无 / 3条码 |
| `0x24` | RES_LEN | 结果长度 |
| `0x25` | MACH_STATE | 0空闲 1等卡 2识别 3有结果 4故障 |
| `0x26` | ERR | 错误码 |
| `0x28` | GATE_DEG | 舵机当前角度 |
| `0x29` | CLR | 写 0xA5 清结果 |
| `0x40`~`0x5F` | RES_BUF | **结果缓冲区 32 字节** |

### 指令（写 `0x00`）

| 值 | 作用 |
|---|---|
| `0x01` | 复位（停带、舵机回静止位、清结果） |
| `0x03` | 急停（只停皮带） |
| `0x10` / `0x11` / `0x12` | 皮带 正转 / 停 / 反向 |
| `0x20` | 扫码（超时 3 秒） |
| `0x22` | 自动识别（本阶段 = 扫码） |
| `0x23` | 清结果 |
| `0x30` / `0x31` / `0x32` | 舵机 放行 / 挡住 / 直接给角度 |
| `0x40` | 自检（未接） |

## 已知限制（重要）

1. **NFC 没接** —— PN532 的 SPI 驱动需要从 `12-Pn532SpiTest/main.c` 移植，下一阶段做。
2. **扫码枪波特率固定 9600** —— 如果模块实际不是 9600，改 `scanner_init()` 里的 `USART2->BRR` 计算。
3. **扫码结果按"静默 50ms 判帧尾"** —— 如果扫出的内容被截断或粘连，调这个 50ms。
4. **光敏有卡阈值写死 2000**（`main` 循环里）—— 上机后按实测亮/暗值调整。
5. **本文件未编译过**（我这台机器没有 Keil），需要你在 Keil 里 `F7` 验证。
