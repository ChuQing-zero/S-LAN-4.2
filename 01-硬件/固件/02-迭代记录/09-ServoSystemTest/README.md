# 最终测试程序（光敏触发 → 双舵机抬升 → 保持 → 下降 → 限位停机）

S-LAN V4.0 / **STM32F103C8T6 蓝 pill**
纯寄存器 · 不用 CubeMX · 不用 HAL
日期：2026-09-22

> **一句话**：卡牌挡住光敏 1 秒，两个舵机一正一反把平台抬起来，停 2 秒，
> 再一起降下去，**碰到限位开关立刻停**。
>
> ```
>   光敏挡住 1 秒  ──>  抬升 2 秒  ──>  保持 2 秒  ──>  下降（最长 10 秒）
>                                                          ↓
>                                                    碰到限位 1 就停
> ```
>
> ⚠️ **这是所有测试里唯一有硬件损坏风险的一步**。

## ⭐ 零、先搞清楚：你手上是哪种舵机

**这是这一版最大的坑，先看这里。**

两种舵机**接线一样、信号一样（50Hz）、同样的脉冲宽度**，
但**同样的脉冲宽度意思完全相反**：

| 脉冲宽度 | **MG90S（位置舵机）** | **360° 连续旋转舵机** |
|---|---|---|
| **1500µs** | 转到 **90°** | **停** |
| 2200µs | 转到 140° 的位置 | **正转，转多快** |
| 800µs | 转到 40° 的位置 | **反转，转多快** |
| 有位置反馈吗 | ✅ 有，内部有电位器 | ❌ **没有** |
| 你给的是 | **目标位置** | **速度命令** |

### ⚠️ 这就是"按了限位不急停"的原因

上一版程序是按 **MG90S** 写的。"停机"的做法是**不再给它新脉冲**：

| | 结果 |
|---|---|
| **MG90S** | 它自己刹在原地 ✅ 看起来完全正常 |
| **360° 舵机** | ⚠️ **最后一次给的脉冲是"速度"，不再更新 = 它按那个速度一直转下去** |

所以限位闭合后，程序**确实**进了 IDLE 状态、`cyc` 也加了 1、串口显示"停了"——
**但电机还在转**，一路顶到机械限位。

> **结论：360° 舵机必须被【明确告诉】它停 —— 显式写 1500µs。**
> 代码里所有停机都走 `servos_halt()`，这个函数就是干这件事的。

### 现在文件顶部是这么设的

```c
#define SERVO_CONTINUOUS   1     ← 1 = 360° 连续旋转（现在台上这个）
                                 ← 0 = MG90S 位置舵机（正式版这个）
```

> ⚠️ **烧到正式板子之前必须改回 0。** BOM 和 `01-单元板方案.md` 写的是 MG90S。

## 一、完整的动作时序

```
   ┌────────────────────────────────────────────────────────────────┐
   │  步骤 0   等光敏被遮挡                                           │
   │           必须【连续】遮住 1.0 秒，中途亮一下就从 0 重新数        │
   ├────────────────────────────────────────────────────────────────┤
   │  步骤 1   抬升                                          2.0 秒   │
   │           舵机 1（PB10）正转     2200µs                          │
   │           舵机 2（PB11）反转      800µs                          │
   │           一起转 2 秒，然后停                                    │
   ├────────────────────────────────────────────────────────────────┤
   │  步骤 2   保持                                          2.0 秒   │
   │           两个都写 1500µs = 停                                   │
   │           （平台靠齿轮箱自锁停住，不靠电机）                      │
   ├────────────────────────────────────────────────────────────────┤
   │  步骤 3   下降                                        最多 10 秒  │
   │           舵机 1 反转 800µs，舵机 2 正转 2200µs                  │
   │           ⚡ 限位 1（PB9）一闭合 → 【当拍写 1500µs 停机】         │
   │           ⏱ 10 秒还没碰到就放弃，计一次超时，也要停机            │
   ├────────────────────────────────────────────────────────────────┤
   │  回到步骤 0（要等光敏先恢复，见第六节"重新武装"）                 │
   └────────────────────────────────────────────────────────────────┘
```

## 二、⭐ 限位开关的两条规则

**就两条，都很重要：**

### 规则 1 —— 一一对应，各管各的

| | 限位 1（PB9）| 限位 2（PB5）|
|---|---|---|
| **管谁** | **只停舵机 1**（PB10）| **只停舵机 2**（PB11）|
| 管别的舵机吗 | ❌ 不管 | ❌ 不管 |

**没有"全停"开关。** 一边到位了就停在那，另一边继续降，
**已经停下的那一边不会被重新启动**（代码里用 `g_lock3` / `g_lock4` 锁住）。

### 规则 2 —— 只在【下降】阶段有效

```
   抬升阶段  按限位 1 或 2  ──>  ❌ 完全没影响，继续走
   保持阶段  按限位 1 或 2  ──>  ❌ 完全没影响，继续走
   下降阶段  按限位 1        ──>  ✅ 舵机 1 立刻停
   下降阶段  按限位 2        ──>  ✅ 舵机 2 立刻停
```

### ⚠️ 为什么抬升阶段按了不停？

**因为一轮刚开始的时候，平台就在最底下 —— 两个限位开关本来就是闭合的。**

这不是"触发"，这是**正常的静止状态**。如果抬升阶段也认它，
那机器一启动就会立刻自己停住，**永远动不了**。

所以程序每一圈都在读这两个开关（灯 1 / 灯 2 会跟着亮），
**但只在 `ST=LOWER` 的时候才真的去停舵机**。

### ⭐ 停机延迟是多少

程序每 20ms 跑一圈，**限位判断在每一圈的最前面**（排在 ADC 采样和串口打印之前，
因为它俩慢）。所以从开关闭合到 1500µs 写进舵机，**最差 20ms**。

### ⭐ 只有一边到位会怎样

**10 秒超时兜底。** 到点了两边一起停，`to` 和 `one` 都加 1，
串口上的 `n1` / `n2` 会告诉你**是哪一边没到位**：

```
   n1=1 n2=0   →  舵机 1 到位了，舵机 2 没有
```

> ⚠️ **`one` 一直涨 = 机构问题，不是代码问题。** 没到位的那一边，
> 舵机已经顶着东西堵转好几秒了 —— 会烧。**先去查那一边的开关和连杆。**

## 三、⚠️ 接线 —— 供电那一条先看

### ⚠️⚠️ 舵机绝对不能从蓝 pill 的 5V 取电

```
   ❌ 错的：  蓝pill 5V ──> 舵机红线
              → 两个舵机堵转时能拉 1.5A 以上，
                蓝pill 的 USB 供电撑不住，
                结果是【单片机复位 / 舵机乱抖 / 电脑 USB 口保护】

   ✅ 对的：  外部 5V 电源 ──> 舵机红线
              外部 5V 的 GND ──┬──> 舵机棕线
                               └──> 蓝pill GND    ← 必须共地！
```

**不共地的话信号线没有参考电平，舵机会乱转或者不动。**

> ⚠️ 也别把舵机电源提到 6V —— 逻辑高要求会变高，3.3V 信号不一定认得出来。

### ① 两个舵机

```
   舵机 1                          蓝pill
   ┌──────┐
   │ 橙 ●─┼──────────────>  PB10   ← TIM2_CH3
   │ 红 ●─┼──────> 外部 5V 正
   │ 棕 ●─┼──────> 外部 5V 负 ────> 还要再接一根到 蓝pill GND
   └──────┘

   舵机 2                          蓝pill
   ┌──────┐
   │ 橙 ●─┼──────────────>  PB11   ← TIM2_CH4
   │ 红 ●─┼──────> 外部 5V 正      ← 和舵机 1 共用同一个电源
   │ 棕 ●─┼──────> 外部 5V 负
   └──────┘
```

> 信号线串 **100Ω** 是 BOM 里的要求。面包板上不加也能跑，
> **但画 PCB 时别忘了**。

### ② 两个限位开关

```
   限位开关 1（管舵机 1）             蓝pill
   ┌────────┐
   │ COM ●──┼──────────────>  PB9
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘

   限位开关 2（管舵机 2）             蓝pill
   ┌────────┐
   │ COM ●──┼──────────────>  PB5
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘
```

**必须用 COM + NC（常闭）** —— 这样**线断了 = 读到"已触发" = 停机**。
⚠️ 用 NO 的话线断了等于"没到位"，**360° 舵机没有位置反馈，
会一直压下去把机构顶坏。**

### ③ 四颗指示灯

```
   PB14 ──[ 470Ω ]── LED1 长脚        LED1 短脚 ──> GND
   PB15 ──[ 470Ω ]── LED2 长脚        LED2 短脚 ──> GND
   PA11 ──[ 470Ω ]── LED3 长脚        LED3 短脚 ──> GND
   PA12 ──[ 470Ω ]── LED4 长脚        LED4 短脚 ──> GND
```

| 灯 | 引脚 | 亮的时候表示 |
|---|---|---|
| **1** | PB14 | 限位 1 触发（原始电平）|
| **2** | PB15 | 限位 2 触发（原始电平）|
| **3** | PA11 | 光被挡住 = 检测到卡 |
| **4** | PA12 | **正在执行一轮**（抬升 / 保持 / 下降）|
| — | PC13 | 板载灯，1Hz 心跳 |

> 灯 1 / 灯 2 是**原始电平** —— 开关一闭合就亮，不管程序停不停。
> ⭐ **这两个灯是你按开关时最快的反馈。**

### ④ 光敏电阻

```
   +3V3 ──[ 光敏 GL5528 ]──┬──[ 10kΩ ]── GND
                            │
                            └──> PA0（脚 10）
```

> ⚠️ **必须是 +3V3，不能是 +5V** —— PA0 不 5V 耐受，接 5V 会烧引脚。

### ⑤ 串口

```
   CH340 TXD ──> PA10        RXD ──> PA9        GND ──> GND        VCC 不接
```

> ⚠️ 这一步**串口不是可选的**。状态机靠串口看，不接串口等于蒙眼调试。

## 五、应该看到什么

### ① 上电

```
   板载灯（PC13）慢闪 3 下              = 程序在跑
   两个舵机立刻收到 1500µs              = 应该是【静止不动】
   灯 1 / 灯 2 灭                       = 两个限位都没触发
```

> ⚠️ ⭐ **上电后舵机要是【自己慢慢转】，说明 1500µs 不是它的准确停点。**
> 见第八节"停机点微调"。

> ⭐ **上电后舵机完全不响应**（连抖都不抖）→ 最可能是 **TIM2 重映射没生效**。
> PB10/PB11 默认不是 TIM2 的通道，必须选"部分重映射 2"。
> 代码里那两行 `AFIO->MAPR` 就是这个，**不能删**。

### ② 串口（115200）

```
   =====================================================
     S-LAN V4.0   system test with servos
        servo 1 PB10   rises forward
        servo 2 PB11   rises backward
        limit 1 PB9    stops servo 1  (lower only)
        limit 2 PB5    stops servo 2  (lower only)
        light   PA0    card detect, needs 1.0 s
     cycle: rise 2s, hold 2s, lower <= 10s
     limit switches do NOTHING during rise or hold.
     servos: 360 deg CONTINUOUS - pulse is a speed,
     so every stop writes 1500us explicitly.
     clock: PLL, 72 MHz - good
   =====================================================

   SW1= SW2= ADC=  TH=  hold=  ST=  cyc=  to= one= n1= n2= nl=
   SW1=0 SW2=0 ADC= 3421 TH= 2000 hold= 0.0s ST=IDLE cyc=  0 to=  0 one=  0 n1=0 n2=0 nl=  0  [clear  ]
```

| 字段 | 意思 |
|---|---|
| `n1` | **舵机 1** 这一轮下降到位了没（0/1）|
| `n2` | **舵机 2** 这一轮下降到位了没（0/1）|
| `one` | 有几轮下降**只有一边**到位 |
| `nl` | ⭐ 有几轮**有一边没离开底部**（抬升白走了）|

> `n1` / `n2` 每轮下降开始时清零，所以 `ST=LOWER` 时它们是**实时进度**：
> `0/0` 都还没到，`1/0` 舵机 1 停了舵机 2 还在降，`1/1` 两边都到了。

### ⭐⭐ `nl` 是什么，为什么要盯它

**360° 舵机的抬升是纯时间，没有位置反馈** —— 程序没办法知道平台到底动没动。
**唯一的证据就是：抬升完了之后，限位开关有没有松开。**

所以下降一开始，程序会**先快照一下两个开关**：

| 下降刚开始时 | 说明 | 程序怎么做 |
|---|---|---|
| 开关**开着** ✅ | 抬起来了，正常 | 正常下降 |
| 开关**还闭着** ❌ | **这一边根本没离开底部** | **把它停掉，`nl` 加 1**，串口报警 |

### ⭐ 如果 `nl` 涨了，串口会长这样

```
... nl=  1  [clear  ]  <<< LIMIT 2 NEVER OPENED - CHECK ITS WIRE
```

**看到这行不要去翻舵机代码** —— 它说的是**限位 2 从头到尾就没松开过**。

> ⚠️ 这**几乎总是接线问题**：限位开关 NC 那根线**没有真正接到 GND**
> （掉出来了 / 插错排了）。上拉输入悬空就读成 1 = "已闭合"，
> 于是程序认为**舵机 2 一进入下降就已经到底了**，立刻把它停掉。
>
> **最快的确认办法：抬升的时候看灯 2。**
> **灯 2 应该在平台升起来之后【灭掉】。如果它一直亮着，就是线的问题。**

> ⚠️ **为什么不停下来让它硬降**：既然那一侧的开关从头到尾没松开，
> 说明臂就没离开过底部 —— 再往下压只是**顶在一个它本来就靠着的死点上**，
> 舵机会堵转。

### ③ 完整跑一轮应该看到

| 时刻 | 灯1 | 灯2 | 灯3 | 灯4 | 串口 ST= | n1 n2 | 舵机 |
|---|---|---|---|---|---|---|---|
| 待机 | 灭 | 灭 | 灭 | 灭 | `IDLE ` | 0 0 | **静止** |
| 手挡住光敏 | 灭 | 灭 | **亮** | 灭 | `IDLE ` | 0 0 | 静止，`hold` 开始涨 |
| 遮满 1 秒 | 灭 | 灭 | 亮 | **亮** | `RISE ` | 0 0 | **开始转** |
| 抬升 2 秒 | **灭** | **灭** | 亮 | 亮 | `RISE ` | 0 0 | 一直转 |
| 保持 2 秒 | 灭 | 灭 | 亮 | 亮 | `HOLD ` | 0 0 | **停住** |
| 下降中 | 灭 | 灭 | 亮 | 亮 | `LOWER` | 0 0 | **反方向转** |
| **按下限位 1** | **亮** | 灭 | 亮 | 亮 | `LOWER` | **1** 0 | **舵机1停，舵机2还降** |
| **再按下限位 2** | 亮 | **亮** | 亮 | **灭** | `IDLE ` | 1 **1** | 两边都停 |
| 手也拿开 | 灭 | 灭 | 灭 | 灭 | `IDLE ` | 0 0 | 静止，`cyc` 变成 1 |

> ⭐ **抬升那一行的灯 1 / 灯 2 必须是灭的。** 平台升起来之后就应该离开两个开关。
>
> **如果抬升完了灯 1 / 灯 2 还亮着** → 下降一开始程序会**先快照**这两个开关，
> 谁还闭着就判定"它根本没离开底部"，`nl` 加 1，并在串口甩出
> `<<< LIMIT n NEVER OPENED - CHECK ITS WIRE` —— **哪一边亮，`LIMIT` 后面就是哪个数字。**
>
> 这时候别去调下降的代码：**灯亮 = 线的问题**（先查），**两个灯都灭但 `nl` 还在涨 = 真的没抬起来**。

> ⭐ 注意中间那一行：**`ST` 还是 `LOWER`** —— 只有一边到位，这一轮还没结束。

> **下降不用真的等 10 秒。** 10 秒是"一直没碰到限位"时的放弃时间。
> 正常情况你手一按限位 1，它**当拍就停**（20ms 内），`cyc` 加 1。

### ④ ⭐ 试"各管各的"（这一版的重点）

**下降过程中，只按限位 1（PB9）：**

| | 应该发生 |
|---|---|
| 灯 1 | **亮** |
| **舵机 1** | **立刻停** |
| **舵机 2** | **⚠️ 继续降** |
| 串口 | `n1=1 n2=0` |

**再按限位 2（PB5）：**

| | 应该发生 |
|---|---|
| 灯 2 | 亮 |
| 舵机 2 | **也停** |
| 串口 | `n1=1 n2=1` → `ST` 变 `IDLE`，`cyc` 加 1 |

**抬升 / 保持阶段按任何一个：**

| | 应该发生 |
|---|---|
| 灯 1 / 灯 2 | **会亮**（它是原始电平，一直跟着）|
| 舵机 | **⚠️ 完全不停，继续走** ← 这是设计要的 |
| 串口 | `SW1=1` 或 `SW2=1`，但 `ST` 不变，`n1`/`n2` 不变 |

**如果按了不停**，按这个顺序查：

| # | 查什么 |
|---|---|
| 1 | 现在是 `ST=LOWER` 吗？抬升 / 保持阶段本来就不停 |
| 2 | 灯 1 / 灯 2 亮了吗？**不亮 = 开关根本没被读到** → 查 NC 有没有接到 GND |
| 3 | 灯亮了但舵机还转 → 回来告诉我，那是代码问题 |

## 六、⚠️ 360° 舵机的三个硬伤（正式版要换 MG90S 的原因）

**这一节很重要，别跳过。**

### ① 没有位置反馈 —— 抬升多少只能靠时间"猜"

MG90S 你给它 140°，它就转到 140°。**360° 舵机没有这个能力** ——
它只知道"转多快"，不知道"转到哪了"。

所以 **"抬升高度" = 转速 × 时间**，而转速会随电池电压、负载变化：

| | 后果 |
|---|---|
| 电池从 5.0V 掉到 4.5V | 同样的 2 秒，**抬升高度变矮** |
| 平台上的东西重了 | 同样的 2 秒，**抬升高度变矮** |
| 温度变化 | 也有影响 |

> ⭐ **而且抬升方向【没有限位开关】** —— 也就是说，
> 万一 2 秒转多了，**没有任何东西会阻止它撞到顶**。

### ② "保持 2 秒"这一步，360° 舵机只能靠齿轮箱自锁

位置舵机是靠电机**主动顶住**。360° 舵机没有位置概念，
只能写 1500 = 停，然后**指望齿轮箱的摩擦力扛住平台的重量**。

> ⚠️ **如果保持的这 2 秒里平台自己往下沉** → 说明齿轮箱太松，
> **这一步 360° 舵机做不了。**

### ③ 停机点可能不准 —— 电机会"爬"

1500µs 只是**名义**中点。有些舵机的死区不是正好在 1500，
**待机时会慢慢爬**。见第八节怎么调。

## 七、⭐ 上电前必查清单

```
   □ 1. 舵机的红线【没有】接在蓝 pill 的 5V 上
   □ 2. 外部 5V 电源的负极，有一根线接到了蓝 pill 的 GND
   □ 3. 舵机橙线在 PB10 / PB11（不是 PA2 / PA3）
   □ 4. 两个限位开关用的是 COM + NC，不是 COM + NO
   □ 5. 两个限位开关的 NC 确实接到了 GND
   □ 6. 光敏分压用的是 +3V3，不是 +5V
   □ 7. 四颗灯的长脚（正极）朝电阻那一侧
   □ 8. 串口 TXD/RXD 没接反，CH340 的 GND 接了
   □ 9. 舵机现在【没有】装在机构上（第一次上电要空转）
   □ 10. 手边够得着电源开关
```

> ⭐ **第 9 条**：第一次上电**让舵机空转**，别急着装机。
> 先确认转向对不对、限位停机管不管用，再装到机构上去。
> **装在机构上再发现方向反了，可能已经顶坏了。**

## 八、可以调的地方（都在 main.c 顶部）

| 想改什么 | 改哪个 | 现在是多少 |
|---|---|---|
| **舵机类型** | `SERVO_CONTINUOUS` | **1**（360°）⚠️正式版改 0 |
| 光要遮多久才启动 | `BLOCK_MS` | 1000 |
| 抬升多久 | `RISE_MS` | 2000 |
| 保持多久 | `HOLD_MS` | 2000 |
| 下降最多等多久 | `LOWER_TIMEOUT_MS` | 10000 |
| **停机点** | `SERVO_MID_US` | 1500 |
| **转速** | `SERVO_SPAN_US` | 700（1000 = 满速）|
| 光敏阈值 | `THRESHOLD` | 2000 ⚠️**占位值** |

### ⭐ 停机点微调（电机会自己爬的时候做）

**待机时舵机慢慢转 → 1500µs 不是它的准确停点。**

```
   每次改 10~20，重新编译下载，看还爬不爬：
       往一个方向爬 → 把 SERVO_MID_US 加大 20
       往另一个方向爬 → 把 SERVO_MID_US 减小 20
   调到【完全不爬】为止，把那个数记下来。
```

> ⚠️ 两个舵机的停点**可能不一样**。真要精细，就得把
> `servos_halt()` 里的两个数分开写。

### 转速怎么调（决定抬升高度）

**转速 × 时间 = 抬升高度。** 现在 `SERVO_SPAN_US = 700`。

```
   抬升不够高 → 加大 SERVO_SPAN_US（朝 1000 走），或者加长 RISE_MS
   抬升太多   → 减小 SERVO_SPAN_US，或者缩短 RISE_MS
```

> ⚠️ **不要一上来就用 1000（满速）** —— 空载满速会让舵机每次
> 都撞到自己的内部限位，**齿轮箱很快就废了**。

### ⚠️ 转向反了怎么办

**"哪个方向叫正转"没有统一标准**，同一型号不同批次都可能相反。

```
   某一个舵机转反了 → 把它那两个数对调：
        US_RISE_1  ←→  US_DOWN_1        （或者 2 的两个）
   别的都不用动。
```

## 九、排查

| 现象 | 原因 |
|---|---|
| **上电没有慢闪 3 下** | 程序没跑 → 复位 / 查 BOOT0 / 勾 `Reset and Run` / Flash 算法没加 |
| ⭐ **按限位不急停** | ① **现在是抬升/保持阶段** —— 这两个阶段本来就不停 ② **灯没亮 = 开关没被读到** → 查 NC 到 GND 的线 |
| **按限位 1 结果舵机 2 也停了** | 不该这样。回来告诉我 |
| **按限位 1 舵机 1 不停** | 先在 `ST=LOWER` 下试；还不行就看灯 1 亮不亮 |
| ⭐ **到 IDLE 了但电机还在转** | 这**正是上一版的 bug**，这一版应该没有了。还有的话回来告诉我 |
| ⭐ **舵机完全不动** | ① **TIM2 重映射没生效**（最常见）② 没供电 ③ **没共地** ④ 橙线插到 PA2 / PA3 |
| ⭐ **舵机乱抖 / 单片机自己复位** | **舵机从蓝 pill 取电了** → 改外部 5V（第三节）|
| **待机时舵机慢慢爬** | 1500µs 不是它的停点 → 见第八节 |
| **一个舵机转、一个不转** | PB10 或 PB11 有一根**信号线**没插实 |
| ⭐ **上升转了、下降一下都不转** | 那一边的限位**在抬升之前就已经是闭合的** → 下降一开始就被判"已经到底"停掉。**看串口有没有 `<<< LIMIT n NEVER OPENED`**，再看那个灯抬升时灭不灭。**代码这一版已经改好，剩下的基本是接线**（§532 那一条）|
| **两个舵机转向一样** | `US_RISE_1` / `US_RISE_2` 应该一个大于 1500 一个小于 |
| **保持阶段平台自己往下沉** | ⚠️ 齿轮箱太松，**360° 舵机做不了这一步** → 见第六节 |
| ⭐ **上电就一直不停** / 不遮光敏也启动 | **阈值不对**，`TH=2000` 是占位值 → 见下 |
| ⭐ **怎么遮都不启动** | 同上，也是阈值 |
| **灯 2 常亮，并且 `nl` 一直涨** | 限位 2 的**线掉了**（或 NC 没接到 GND）。上拉输入悬空读成 1 = "已闭合"，于是下降一开始就认定**舵机 2 已经到底**，直接把它停掉 —— **表现就是"舵机 2 上升会转、下降一下都不转"**。**这是设计要的 fail-safe**（断线 = 当已到位 = 提前停机），串口会点名 `<<< LIMIT 2 NEVER OPENED - CHECK ITS WIRE` |
| **下降跑满 10 秒才停，`to` 加 1** | 看 `n1` / `n2` 是哪一个没到：① 那一边的限位没接好 ② 那一边降得太慢到不了 ③ 那一边机构卡住 |
| ⭐ **`one` 一直加** | **有一边总也到不了。** 机构问题，不是代码 —— 那一边的舵机已经顶着东西堵转好几秒了 |
| ⭐ **`nl` 一直加，串口出现 `<<< LIMIT n NEVER OPENED`** | **有某一边抬升时根本没离开底部**（开关从头到尾没松开）。**先看抬升的时候灯 1 / 灯 2 灭不灭**，再对下面两条 |
| ↳ **只有一边报警**（`LIMIT 1` **或** `LIMIT 2`，只有**一个**数字）| **那一边的线的问题** —— NC 没真正接到 GND（悬空读成 1 = "已闭合"）。**那个灯会一直亮着**。**改接线，不是改代码** |
| ↳ **两边都报警**（`LIMIT 1 2`，**两个**数字）| **真的没抬起来** —— ① 舵机没供电 ② **转向反了**（见第八节）③ 转速太小 / `RISE_MS` 太短 |
| **`to` 一直加，而且舵机发烫** | ⚠️ 舵机**堵转**了。**断电**，先调转速/时间 |
| **串口一个字都没有** | ① TXD/RXD 接反 ② CH340 的 GND 没接 ③ 波特率不是 115200 |
| **串口全是乱码** | 看开机那行是不是 `NOT PLL` —— 晶振没起振 |

### ⭐ 先量阈值，再谈别的

**`THRESHOLD` 现在还是 2000 这个占位值**，从来没在你的分压上量过。
在改掉它之前，"光敏触发"这件事本身就不准 —— **别去怀疑舵机代码**。

```
   跑 ../08-SystemTest，反复遮挡 20 次，记下：
       max = ______   （不挡时）
       min = ______   （挡住时）
       阈值 = (min + max) / 2 = ______
   填进 09 的 #define THRESHOLD
```

### ⭐ 又是接触不良

`07` / `08` 都栽在这上面：**板子没插紧 / 杜邦线松**，
表现得像"引脚坏了""灯坏了""程序错了"。

**这一步更危险**，因为它会伪装成**限位开关误动作** ——
而限位是**唯一的停机保护**。**养成习惯：**

```
   先怀疑接触  ──>  再怀疑器件  ──>  最后怀疑代码
     5 秒            5 分钟           30 分钟
```
