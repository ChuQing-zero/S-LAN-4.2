## 唯一要改的一行

```c
#define BOARD_ADDR_7BIT   0x20      /* <<<<<< 改这一行 >>>>>> */
```

**就在文件第 27 行**（打开就在眼前，不用翻）。上面有一大段注释横幅，很好找。

| 烧哪块板 | 改成 |
|---|---|
| 分拣 **A** | `0x20` |
| 分拣 **B** | `0x21` |
| 分拣 **C** | `0x22` |
| 分拣 **D** | `0x23` |

**改完 `F7` 编译、`F8` 下载。除此之外一个字都不用动。**

---

## 烧完的检查（很重要）

| 板子上的现象 | 说明 |
|---|---|
| PC13 慢闪 3 下 → 4 灯依次各亮一次 → **全灭** → PC13 每秒翻一次 | ✅ 从机固件在跑 |
| 4 颗灯**一直依次追着跑** | ❌ 还是 `17-Stm32MinBlink`，没覆盖成功 |

从机固件正常情况下 **4 颗灯是不亮的**，只有 Nano 下命令才亮。

---

## 烧四块板的流程

1. 用**同一个 Keil 工程**（你原来那个能用的）
2. 工程里的 `main.c` 换成这份 `main.c`
3. 第 27 行改 `0x20` → `F7` → `F8` → 烧到 **A 板**
4. 第 27 行改 `0x21` → `F7` → `F8` → 烧到 **B 板**
5. 改 `0x22` → 烧 **C 板**
6. 改 `0x23` → 烧 **D 板**

> ⚠️ Keil 工程里**只能有一个 `main.c`**。加了第二份会报重复定义，或者编了错的那份。
