# 流水灯测试（经典跑马灯）

S-LAN V4.0 / **STM32F103C6（蓝 pill）**
纯寄存器 · 不用 CubeMX · 不用 HAL
日期：2026-10-04

> **一句话**：4 颗指示灯**一颗一颗往下走**，同一时刻**只有一颗亮**，走完一轮停一下再从头来。
>
> ```
>   PB14 → PB15 → PA11 → PA12 → 全灭 0.4 秒 → 再从头
>      每步 150 毫秒，一轮正好 1 秒
> ```
>
> **不接开关、不接光敏、不接 I²C、不接舵机。** 只验：**芯片跑起来了没有 + 4 颗灯的通路好不好。**

---

## ⚠️ 先看清楚：这个和 `07-LedChaseTest` **不是一回事**

`07-LedChaseTest` 文件夹名字里虽然有 "Chase"，但它做的**不是流水灯**，是**点名**
（每颗灯闪自己编号的次数：1下、2下、3下、4下），它的 README 里专门写了
「为什么不用流水灯」。

两个的用途正好相反，**别搞混，也别互相替代**：

| | **10-RunningLightTest（本文件）** | **07-LedChaseTest** |
|---|---|---|
| 灯怎么亮 | 一颗一颗往下走，**同时只亮一颗** | 一颗一颗来，每颗**闪自己的编号** |
| 一轮多久 | **1 秒** | 约 8 秒 |
| 能回答什么 | **芯片活了没有？灯排基本通了没有？** | **哪一颗灯 / 哪一根线坏了？** |
| 分得清是哪颗灯吗 | ❌ 分不清 | ✅ 分得清清楚楚 |
| 什么时候用 | **先跑这个** | 这个发现有灯不亮，**再换 07 去查** |

> **一句话记法**：**10 看"活没活"，07 查"哪颗坏"。**

## 一、4 颗灯分别是哪 4 颗

| 顺序 | 引脚 | 脚号 | 右排位置 | 含义 |
|---|---|---|---|---|
| 第 1 颗 | **PB14** | 27 | 从下往上第 3 根 | 限位 1 灯 |
| 第 2 颗 | **PB15** | 28 | 从下往上第 4 根 | 限位 2 灯 |
| 第 3 颗 | **PA11** | 32 | A9 上面第 1 根 | 卡牌检测灯 |
| 第 4 颗 | **PA12** | 33 | A9 上面第 2 根 | 通信灯 |

> ```
>       A12   ← 第 4 颗亮
>       A11   ← 第 3 颗亮
>       A10   串口
>       A9    串口
>       A8    ✂ 空着
>       B15   ← 第 2 颗亮
>       B14   ← 第 1 颗亮
>       B13
>       B12
> ```
>
> 这 4 个引脚和 `../../../electronics/01-单元板方案.md` §6.1 的 PCB 分配**完全一致**，
> 所以这块测试板跑通 = 正式板上这 4 根线是对的。

### ⚠️ 第 5 颗灯不参与流水

**电源灯**直接挂 +3V3（串 470Ω），**上电就常亮，永远不闪**。**这是对的，不是故障。**

反过来它有用：**电源灯要是灭的，说明 3.3V 根本没上来**，别的灯也不可能亮。

## 二、接线（4 颗灯，8 根线）

**4 颗接法完全一样**，只是引脚不同：

```
   PB14 ──[ 470Ω ]── LED1 长脚（正极）
                      LED1 短脚（负极）──> GND

   PB15 ──[ 470Ω ]── LED2 长脚          LED2 短脚 ──> GND

   PA11 ──[ 470Ω ]── LED3 长脚          LED3 短脚 ──> GND

   PA12 ──[ 470Ω ]── LED4 长脚          LED4 短脚 ──> GND
```

> **电阻夹在「引脚」和「LED 长脚」之间**，LED 短脚去 GND。
> **长脚 = 阳极（正极）**，也可以看灯珠内的小方块，**小的一边是正极**。
> 接反了不亮也不烧（才 3mA），掉个头就行。

### 串口（可选，但建议接）

```
   CH340 TXD ──> PA10        RXD ──> PA9        GND ──> GND        VCC 不接
```

接上串口后，**每点亮一颗灯，串口会同步报出它的名字**，边看串口边看灯，最准。

### ⚠️ 电阻别用错

| 用什么 | 电流 | 效果 |
|---|---|---|
| **470Ω** ✅ | 约 2.5–3 mA | 就按这个做 |
| 220Ω ✅ | 约 5 mA | 更亮，也能用 |
| 1kΩ ❌ | 约 1.3 mA | **暗到看不出来** |

LED 用**红 / 绿 / 黄**。蓝、白的 Vf ≈ 3.2V，**3.3V 供电根本点不亮**。

## 三、Keil 里怎么用

```
① 在 10-RunningLightTest 文件夹里新建 Keil 工程

② Project → Manage → Run-Time Environment
        [x] CMSIS  → CORE
        [x] Device → Startup

③ 把本文件夹的 main.c 整份替换掉工程里的 main.c

④ Options for Target → Device      选 STM32F103C6（别改）
   Options for Target → Debug       下拉选 【ST-Link Debugger】
   Options for Target → Flash Download
        → ⭐ Programming Algorithm 不能是空的
          【Add】→【STM32F10x 128KB Flash】→ Add → Close
        → 勾 【Reset and Run】
        → 勾 【Erase Full Chip】

⑤ F7 编译  →  F8 下载
```

**不用勾 `Use MicroLIB`。**

> ⚠️ 这份 main.c 开头默认定义的是 **`STM32F10X_LD`**（低密度，F103C6，配
> `startup_stm32f10x_ld.s`）。如果你是拿 C8 的现成工程改的，把开头那句
> `#define STM32F10X_LD` 改成 **`STM32F10X_MD`**，否则链接阶段会报一堆重复定义。

## 四、应该看到什么

```
① 上电：板载小灯（PC13）慢闪 3 下          = 程序在跑

② 然后开始流水，一轮正好 1 秒：

     灯1 (PB14) 亮 0.15 秒
     灯2 (PB15) 亮 0.15 秒
     灯3 (PA11) 亮 0.15 秒
     灯4 (PA12) 亮 0.15 秒
     全灭 0.4 秒                       ← 一轮结束，板载小灯翻一次

③ 串口同步刷出：
     -- round 1 --
       [1] PB14  limit switch 1 lamp
       [2] PB15  limit switch 2 lamp
       [3] PA11  card detect lamp
       [4] PA12  comm lamp
       (all off)
     -- round 2 --
       ...
```

**关键判据：板载小灯（PC13）大约 1 秒翻一次。**
它翻就说明主循环在转，程序**百分之百在跑**。

## 五、怎么看结果

| 现象 | 结论 |
|---|---|
| **4 颗灯依次亮，循环流畅** ✅ | 芯片、时钟、GPIO、4 颗灯全部正常，可以进下一步 |
| **4 颗都亮但顺序乱** | 有灯的线插错针了 → **换 `07-LedChaseTest` 去查是哪一根** |
| **某颗从来不亮，其余正常走** | 那颗 LED / 那个电阻 / 那 2 根线的问题 → 同样换成 07 |
| **只有板载灯闪，4 颗外接全不亮** | ① 3.3V 没接到 LED 那侧 ② 4 根引脚线全插错排 ③ 看下面"共性问题" |
| **全灭，板载灯也不闪** | **程序没跑起来**：晶振没起振 / 没下载进去 / 复位脚被拉低 |
| **灯一直常亮不灭** | 负极接到了别的引脚而不是 GND |
| **电源灯不亮** | 3.3V 没上来，先查供电 |

### ⭐ 灯不亮，**先查接触**

搭板初期 **PB14 那颗灯不亮**，当时怀疑引脚坏了，把灯 1 挪到 PA8 去绕 ——
**最后发现是板子/杜邦线没插紧。**（这段教训写在 `07-LedChaseTest/README.md` 里）

| 教训 | |
|---|---|
| **板子没插紧 / 杜邦线松** | 会伪装成"引脚坏了""灯坏了""程序错了"，全都长得像 |
| **一次动一样东西** | 别同时怀疑灯、电阻、引脚、代码 |
| **5 秒 vs 5 分钟** | 重插的成本是 5 秒，换一颗灯是 5 分钟，改代码是 30 分钟 |

### 按这个顺序查（从最常见的开始）

| # | 查什么 | 怎么查 |
|---|---|---|
| 1 | **板子和杜邦线插紧没有** | 全部拔掉重插一次，**先做这个** |
| 2 | **电阻和 LED 插在面包板的同一排** | 同一排 5 个孔是**连通的** → 被短路 → 不亮。**两脚必须跨在不同排** |
| 3 | **LED 长脚短脚接反** | 掉个头 |
| 4 | **负极没真接到 GND** | 从好灯的负极位置拉一根线过去试 |
| 5 | **跨了面包板中间的沟** | 中间那条沟**左右不通**，跨沟等于断路 |
| 6 | **引脚认错** | 右排从下往上：B12、B13、B14、B15；A8、A9、A10 再往上，A11/A12 在更上面 |
| 7 | **灯是蓝 / 白的** | 3.3V 点不亮 → 换红/绿/黄 |
| 8 | **用了 1kΩ** | 太暗，看着像不亮 → 换 470Ω |

### 定位"某颗不亮"最快的办法：**搬灯**

把**已知好的那颗灯**的**「引脚那根线」**从 A12 拔下来，插到不闪的那根针上
（电阻、LED、接地线都不动）。然后看那一颗该亮的时候：

| 现象 | 结论 |
|---|---|
| **换过去就亮了** ✅ | **那根针和程序都没问题** → 是你原来接在它上面的**灯或电阻坏了**，或者**根本没接灯** |
| **换过去还是不亮** | **那根针有问题** —— 插错针了，或者那根针没插实 |

## 六、串口没输出怎么办

| 现象 | 原因 |
|---|---|
| **一个字都没有** | ① **TXD/RXD 接反了**（最常见）② CH340 的 GND 没接 ③ 波特率不是 115200 |
| **全是乱码** | ① 波特率不对 ② 看开机那行是不是 `NOT PLL` —— 晶振没起振 |
| **串口里是 `indicator LED roll call`** | ❌ 烧错程序了，那是 07，重新烧 10 |

**没有串口也能用** —— 直接看灯走没走、板载灯翻没翻就行。
