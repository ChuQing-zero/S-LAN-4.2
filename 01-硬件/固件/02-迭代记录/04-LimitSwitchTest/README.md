# 限位开关测试

S-LAN V4.0 / **STM32F103C8T6 蓝 pill**
纯寄存器 · 不用 CubeMX
日期：2026-09-22

> **功能**：板载小灯用**闪烁次数**报告 PB9 / PB5 的电平 ——
> 这样你不用量表就能**验证短接有没有生效**。
>
> ```
>    上电：  3 下【慢】闪（约 2.4 秒）        = 程序在跑
>
>    之后每轮 1.5 秒：
>       PB9 是高电平  →  快闪 1 下
>       PB5 是高电平  →  快闪 2 下
> ```
>
> | 情况 | 快闪次数 |
> |---|---|
> | 什么都没接 / 两根都悬空 | **3 下**（1 + 2）|
> | 只有 PB9 悬空 | **1 下** |
> | 只有 PB5 悬空 | **2 下** |
> | 两根都短接到 GND | **0 下**（灯不闪）|

---

## 一、接线（一共 4 根线）

```
   限位开关 1                       蓝pill
   ┌────────┐
   │ COM ●──┼──────────────>  PB9    ← 丝印 "B9"（脚 46）
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘

   限位开关 2                       蓝pill
   ┌────────┐
   │ COM ●──┼──────────────>  PB5    ← 丝印 "B5"（脚 41）
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘
```

| 问题 | 答案 |
|---|---|
| **开关的另一脚接地，对吧？** | ✅ **对**，NC 那脚接 GND |
| COM 和 NC 谁接 PB9、谁接 GND？ | **都行**，开关是干触点，不分正负 |
| 要不要加电阻？ | ❌ **不用**，用 STM32 内部上拉 |
| ⚠️ PB5 有要注意的吗？ | **有：PB5 不 5V 耐受**，别往它上面接 5V |

### 📍 引脚位置（⚠️ 两根都在**右排**，不是左排）

```
   蓝pill 右排（从上往下找丝印）：

       3V3
       GND
       5V
       B9     ← 限位开关 1 的 COM 接这里（从上数第 4 根）
       B8
       B7
       B6
       B5     ← 限位开关 2 的 COM 接这里（从上数第 8 根）
       B4
       B3
       A15
       A12
       A11
       A10
       A9
       A8
       B15
       B14
       B13
       B12
```

> ⭐ **两根针在右排的上半部分**（B9 和 B5），不再是最底下那几个 ——
> 之前用的 PB12 / PB13 在右排最角落，现在整个挪上来了。
>
> 对照：**PB10 / PB11（舵机）在左排最下面几个**，别和这边搞混。
>
> 面包板的 **GND 轨**接两根线出去，分别给两个开关的 NC 脚。

## 二、先认开关的 3 个脚

KW11 三个脚**没标字**，用 DM40C 打 **蜂鸣档（通断档）**：

| 操作 | 响的两个脚 | 结论 |
|---|---|---|
| **不按拨杆** | 假设 A 和 B 响 | 这俩就是 **COM + NC** ✅ 用这俩 |
| **按住拨杆** | 假设 B 和 C 响 | 这俩是 COM + NO |
| — | **两次都响的那个**（B）| 就是 **COM** |

> 一句话：**不按的时候响的两个脚，就是要用的两个脚。**

## 三、Keil 里怎么用

```
① 在 04-LimitSwitchTest 文件夹里新建 Keil 工程
   （和 03-TwoServoBareMetal 一样的做法）

② Project → Manage → Run-Time Environment
        [x] CMSIS  →  CORE
        [x] Device →  Startup

③ 把本文件夹的 main.c 加进工程，替换掉默认的 main.c

④ Options for Target → Device 标签页
        选 STM32F103C6（和之前保持一致）

⑤ Options for Target → Debug 标签页
        → 下拉选 【ST-Link Debugger】

   Options for Target → Flash Download 标签页
        → ⭐ Programming Algorithm 列表**不能是空的**
          空的就点 【Add】→ 选 【STM32F10x 128KB Flash】→ Add → Close
        → 勾 【Reset and Run】
        → 勾 【Erase Full Chip】

⑥ F7 编译  →  F8 下载
```

> ⚠️ **`system_stm32f10x.c` 要留着** —— 启动文件会调用它里面的 `SystemInit()`。
>
> ⚠️ 用老器件包时**必须** `#include "stm32f10x.h"`（不是 `stm32f1xx.h`），
> 而且前面要先定义密度宏 —— main.c 里已经自动处理了。

## 四、⭐ 验证两根针

### 第 1 步：确认程序在跑

```
上电 / 按复位  →  应该看到 3 下【慢】闪
```

没有慢闪 = 程序没跑 → 按复位键 / 查 BOOT0 / 勾 `Reset and Run`。

### 第 2 步：数快闪的次数

程序跑起来之后，每 1.5 秒报一次：

| 快闪次数 | 意思 |
|---|---|
| **3 下** | 两根都是高电平（**什么都没接**，或者两根都悬空）|
| **1 下** | PB9 高，PB5 低 |
| **2 下** | PB5 高，PB9 低 |
| **0 下** | 两根都低（都被拉到 GND）|

> ⚠️ **慢闪 3 下**（上电那一次）和 **快闪 3 下**（两根都悬空）不一样，
> 看**节奏快慢**就能分。

### 第 3 步：短接到 GND，看哪一组闪消失

```
拿一根杜邦线，一头碰 B9 或 B5，另一头碰 GND 轨
```

| 现象 | 结论 |
|---|---|
| **1 下的那组消失了**（变成闪 2 下）| ✅ B9 认对了（限位 1）|
| **2 下的那组消失了**（变成闪 1 下）| ✅ B5 认对了（限位 2）|
| 闪的次数完全没变 | ❌ 这根针不是 B9/B5，或者没接触好 |

> 💡 蓝 pill 每根针都有丝印，所以不用像以前那样"猜"。这一步是确认
> **程序里配的寄存器位对得上实物** —— 现在 PB9 在 `CRH`、PB5 在 `CRL`，
> 是两个不同的寄存器，容易写错一个，所以这一步值得走一遍。

**两根都验证过之后**，再把开关接上去。

## 五、接开关

```
   开关 1    COM ──> PB9 （右排丝印 B9）
             NC  ──> GND
             NO  ──> 不接

   开关 2    COM ──> PB5 （右排丝印 B5）
             NC  ──> GND
             NO  ──> 不接
```

| 操作 | 快闪次数 |
|---|---|
| 不按开关 | **0 下**（灯不闪）|
| **按住开关 1** | **1 下** ✅ |
| **按住开关 2** | **2 下** ✅ |
| **两个一起按** | **3 下** |
| 松开 | 回到 0 下 |

### ⭐ 验证"断线保护"

**把开关的 NC 那根线从面包板上拔掉** → 快闪次数应该变成 **1 下或 2 下**。

这是设计要的效果：线断了 = 当成"已触发" = 安全停机，而不是继续冲撞机构。

## 六、排查

| 现象 | 原因 |
|---|---|
| **上电没有慢闪 3 下** | 程序没跑 → 按复位键 / 查 **BOOT0** 跳线帽 / 勾 `Reset and Run` |
| **一直闪 3 下，短接哪根都不变** | 接错针了 → 右排从上往下：3V3、GND、5V、**B9**、B8、B7、B6、**B5** |
| **短接时不闪，但一直闪 1 下** | PB9 认对了，PB5 那根针找错了（PB5 在 `CRL`，别和 `CRH` 的位搞混）|
| **按住开关不闪** | ① COM/NC 认反，接到了 **NO** ② NC 没真接到 GND |
| **不按开关就一直闪 3 下** | 开关线没接上（两根针都悬空）|
| **慢闪 3 下都没有** | 程序没跑，或 **Flash Download 里没加算法** |

## 七、为什么必须用 NC（不能接 NO）

| 情况 | NC 接法（本测试）| NO 接法（❌ 不要用）|
|---|---|---|
| 齿条没到 | 低 → 未触发 | 低 → 未触发 |
| 齿条顶到 | 高 → ✅ 触发 | 高 → ✅ 触发 |
| **线掉了 / 插头松了** | **高 → ✅ 触发（安全）** | **低 → ❌ 未触发（危险）** |

**NO 接法下线断了会被读成"没触发"，齿条会继续冲、撞坏机构。锁死 NC。**

## 八、程序里改引脚

`main.c` 顶部几行：

```c
#define SW1_PIN          9           /* 限位开关 1 -> PB9   （脚 46）*/
#define SW2_PIN          5           /* 限位开关 2 -> PB5   （脚 41）*/
#define LED_PIN          13          /* 板载小灯   -> PC13 */
```

**以后做正式板子时**，把指示灯从板载的 PC13 换成外接的 PB14 / PB15：

```c
#define LED_PIN          14          /* 改成 PB14，同时把下面的 GPIOC 改成 GPIOB */
```

> 外接 LED 接法：`PB14 ─[470Ω]─ LED长脚`，`LED短脚 → GND`

> ⭐ **这一步已经做好了** —— 不用自己改这份，直接用
> `../06-IndicatorLedTest/`（限位 + 外接指示灯 PB14/PB15 + 串口，成品）。
> 这份 `04` 留着当**找针工具**用就行。
