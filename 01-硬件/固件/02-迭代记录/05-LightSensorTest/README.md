# 光敏（ADC）测试

S-LAN V4.0 / **STM32F103C8T6 蓝 pill**
纯寄存器 · 不用 CubeMX · 不用 HAL
日期：2026-09-22

> **这是面包板计划里的【阶段 3：ADC —— 光敏电阻】。**
> 限位开关（阶段 2）已经跑通，舵机（阶段 4）提前跑通了，
> 剩下的就这一步，做完就可以直接进【阶段 5：I²C 从机】跟 Arduino 对通。

## 一、这个程序干什么

```
   每 250 毫秒读一次 PA0 上的 ADC 值，从串口打印出来：
        ADC= 3421  min= 3390  max= 3462  TH=2000  N= 0  [ clear   ]
        ADC=  186  min=  186  max= 3462  TH=2000  N= 0  [ BLOCKED ]
        ADC= 3400  min=  186  max= 3462  TH=2000  N= 1  [ clear   ]

   | 字段 | 意思 |
   |---|---|
   | **ADC** | 当前读数，0～4095，4095 = 3.300V |
   | **min** | 上电以来**最小**的读数 |
   | **max** | 上电以来**最大**的读数 |
   | **TH** | 程序里设的阈值 |
   | **N** | 光"恢复"了几次 —— 也就是你遮挡了几个来回 |

   同时板载小灯（PC13）当**没有串口也能用**的指示灯：

        读数 < 阈值（被挡住）  →  小灯 **亮**
        读数 > 阈值（有光）    →  小灯 **灭**
```

> ⭐ **加串口是有原因的**：阶段 3 的通过标准是"**定出一个阈值**"。
> 没有串口你只能靠灯猜，定不出数。所以这一步**必须先有串口**。
> 串口通了以后，阶段 5（I²C）排查也要靠它。

## 二、接线（三组，一共 7 根线）

### ① 光源 LED —— 常亮，不占引脚

```
   +5V ──[ 220Ω ]──[ 白色 LED 长脚 ]──[ 短脚 ]── GND
```

### ② 光敏分压 —— 接 PA0

```
   +3V3 ──[ 光敏电阻 GL5528 ]──┬──[ 10kΩ ]── GND
                               │
                               └──> PA0（脚 10）= ADC12_IN0
```

### ③ 串口 —— 和 CH340 模块

```
   CH340  TXD ──> PA10      （STM32 的 RX）
   CH340  RXD ──> PA9       （STM32 的 TX）
   CH340  GND ──> GND
   CH340  VCC ──> ✂ 不接
```

> ⚠️ **TXD 和 RXD 是交叉的** —— CH340 的 TXD 要接 STM32 的 **RX**。
> 接成 TXD→TX 就没有任何输出，这是最常见的错。

> **只接 3 根线**（TXD / RXD / GND），CH340 的 VCC 不要接。
> 蓝pill 走自己的 USB 供电，CH340 走它自己的 USB，两边只共地，不共电源。

### ⚠️ 两处电压不一样，千万别接反

| | 挂哪个电压 | 为什么 |
|---|---|---|
| **光源 LED** | **+5V** | 白光 LED 的 Vf ≈ 3.2V，挂 3.3V **根本点不亮** |
| **光敏分压** | **+3V3** | PA0 **不 5V 耐受**，接 5V 会**烧引脚** |

## 三、引脚位置

```
   蓝pill 右排（从上往下）：

       3V3
       GND
       5V     ← 光源 LED 的 +5V 从这里取
       B9
       B8
       B7
       B6
       B5
       B4
       B3
       A15
       A12
       A11
       A10    ← ★ 接 CH340 的 TXD（STM32 的 RX）
       A9     ← ★ 接 CH340 的 RXD（STM32 的 TX）
       A8
       B15    ┐
       B14    │  ← 限位开关 2、限位开关 1 在这下面
       B13    │     （04-LimitSwitchTest 用的就是这两根）
       B12    ┘
```

```
   蓝pill 左排（从上往下）：

       VBAT
       C13    （板载小灯）
       C14
       C15
       A0     ← ★ 光敏分压的中点接这里
       A1
       A2
       ...
       B10    ┐
       B11    ┘  ← 舵机信号在这两根
```

> 认针就看**丝印**（A0 / A9 / A10 / 5V），别数行数，不同批次的板子顺序略有差别。

## 四、串口软件怎么设

用任意串口助手（SSCOM / XCOM / 友善串口助手 / VSCode 串口插件都行）：

| 项 | 值 |
|---|---|
| 端口 | CH340 装好驱动后出现的 COM 口 |
| 波特率 | **115200** |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |
| 流控 | 无 |
| 接收区的"加回车换行" | ✅ 勾上 |

## 五、应该看到什么

```
① 上电 / 按复位 → 板载小灯慢闪 3 下        = 程序在跑

② 串口立刻出现：
   =====================================================
     S-LAN V4.0   light sensor test
     PA0 = ADC1_IN0        LED = PC13        TH = 2000
     clock: PLL, 72 MHz - good
   =====================================================
     ...

   ★ 看到 "clock: PLL, 72 MHz - good" 就说明：
       串口线对了 + 波特率对了 + 晶振起了 + 系统时钟真的是 72MHz
       这一行顺手把【阶段 2 的"确认时钟 72MHz"】也一起验了

③ 之后每 250ms 刷一行 ADC=...
```

**拿手挡住光敏电阻** → `ADC` 掉下去、`[ BLOCKED ]`、小灯亮。
**拿开** → `ADC` 涨回来、`[ clear ]`、小灯灭。

## 六、⭐ 怎么定阈值

```
   第 1 步  反复遮挡、拿开，20 个来回（看着 N 涨到 20）
   第 2 步  记下 min 和 max
   第 3 步  TH 取中间值 —— 谁离得远取谁，取 (min + max) / 2 最保险
   第 4 步  改 main.c 顶部的：
                #define THRESHOLD  2000
            改成算出来的数 → 重新编译下载 → 再遮 20 次确认不误判
```

**判断标准（计划里写的）：**

| 项 | 要求 | 实测填这里 |
|---|---|---|
| 有卡（挡住）时的 ADC | — | ______ |
| 无卡（有光）时的 ADC | — | ______ |
| **两值差距** | **越大越好**，理想 > 2000 | ______ |
| **定出的阈值 TH** | 取中间 | ______ |

> **差距不够大怎么办**，按这个顺序试：
> 1. 调整光源和光敏电阻的**对准 / 距离**（最有效）
> 2. 套**遮光筒**（黑色热缩管），挡掉环境光
> 3. 把 10kΩ 换成 **20kΩ** 或 **4.7kΩ**，找最灵敏的点
> 4. 换更亮的光源，或把 220Ω 改小（别超 LED 额定电流）

把上面表格里的数**告诉我**，我帮你写进文档。

> **注意**：正式程序里不会用固定阈值 —— `docs/V4.0-项目计划书.md` §4.4 已经定了
> **开机自校准**（开机记录无卡基线，阈值 = 基线 × 0.6）+ **中值滤波 + 连续 3 次确认**。
> 面包板这一阶段先用固定阈值，只为**确认区分度够不够**。

## 七、遮光筒

**环境光是这个方案最大的敌人** —— 白天和晚上读数会完全不同，不处理的话阈值根本没法定。

```
   光源 LED ──[ 黑色热缩管 ]──>  只留一个小缝
                                   ↓
                              （卡牌从中间过）
                                   ↓
   光敏电阻 ──[ 黑色热缩管 ]──>  只留一个小缝
```

做法：剪两段黑色热缩管，分别套在光源 LED 和光敏电阻上，用打火机/热风枪缩一下。
**测试阶段可以先不套**（先确认电路通），等要定阈值的时候再套上重测一遍。

## 八、排查

| 现象 | 原因 |
|---|---|
| **上电没有慢闪 3 下** | 程序没跑 → 按复位键 / 查 BOOT0 / 勾 `Reset and Run` |
| **串口一个字都没有** | ① **TXD/RXD 接反了**（最常见）② 波特率不是 115200 ③ CH340 驱动没装 ④ **CH340 的 GND 没接** |
| **串口全是乱码** | ① 波特率不对 ② **晶振没起振**，芯片跑在内部 8MHz（看开机那行是不是 `NOT PLL`）|
| **打印 `clock: *** NOT PLL ***`** | 8MHz 晶振没起振 → 蓝pill 是假货 / 晶振虚焊。换一块板试 |
| **ADC 一直是 0** | ① 光敏分压的 +3V3 没接 ② **PA0 认错针了** ③ 10kΩ 没接地 |
| **ADC 一直是 4095** | ① **光敏电阻和 10kΩ 接反了**（应该光敏在上、10k 在下）② PA0 那根线断了 |
| **ADC 跳得厉害（±200）** | 正常，环境光在抖。定阈值时取 min/max 就没问题 |
| **挡住光 ADC 不降反升** | 光敏电阻和 10kΩ 位置对调了 |
| **小灯和串口对不上** | 不会 —— 两个都看同一个 `blocked` 变量 |
