# S-LAN 主控 Nano 通信协议（V6.0）

> 主控：进料板 Nano（ATmega328P）  
> 串口：**115200 8N1**（PC ↔ Nano）  
> 从机：识别单元 `0x10` + 分拣单元 `0x20~0x23`（I²C，50 kHz）  
> 协议风格：沿用 V1.2 逗号分隔文本协议

---

## 一、系统架构

```
PC（主控软件）
    │ USB 串口 115200
    ▼
进料板 Nano（I²C 主站）
    │
    ├── I²C 总线
    │     ├── 0x10  识别单元（扫码 / NFC / 挡片 / 皮带）
    │     └── 0x20~0x23  分拣单元 ×4（舵机 / 限位 / 灯）
    │
    └── 自身外设
          ├── D3  按钮1
          ├── D6  按钮2
          ├── D4/D5  数码管 TM1637
          ├── D7/D8/D9  进料电机
          ├── D11 蜂鸣器
          ├── A0  状态指示灯
          ├── A1  继电器（风扇）
          ├── A2  继电器（灯）
          └── A7  光敏电阻
```

**说明：ESP-01 本期不使用，D10 / D12 空出。D10 为 PWM 脚，可留给补光灯。**

## 二、PC → Nano 命令

### 2.1 单字符命令（沿用 V1.2，向后兼容）

| 命令 | 作用 | 回执 |
|---|---|---|
| `H` | **握手 / 保活** | `[握手] NANO-READY V6.0` |
| `?` | 查询全部状态 | `[状态] ...`（见第三节） |
| `s` | 进料启动（电机持续正转） | `[进料] 电机=RUN` |
| `t` | 进料停止 | `[进料] 电机=STOP` |
| `c` | 进料一张（推送一张卡） | `[进料] 推卡中` |
| `r` | 复位进料计数 | `[进料] 计数=0` |
| `b` | 蜂鸣器响一声 | `[蜂鸣] OK` |

### 2.2 带参数命令（首字符大写，逗号分隔）

#### 进料单元（Nano 自身）

| 命令 | 例子 | 参数说明 |
|---|---|---|
| `M,dir,speed,ms` | `M,F,200,1000` | 电机：`F` 正转 / `R` 反转 / `S` 停；speed=0~255；ms=时长（0=一直转） |
| `O,on\|off` | `O,on` | 状态指示灯 A0 |
| `B,freq,ms,times` | `B,1000,500,1` | 蜂鸣器：频率 / 时长 / 次数（0=无限） |
| `D,text` | `D,1234` 或 `D,BUSY` | 数码管显示 ≤4 字符（数字 / 字母 / 错误码） |
| `Q,ldr` | `Q,ldr` | 读光敏 A7 |
| `F,on\|off` | `F,on` | 风扇继电器 A1 |
| `W,on\|off` | `W,on` | 灯继电器 A2 |

#### 识别单元（0x10）

| 命令 | 例子 | 作用 |
|---|---|---|
| `I,addr` | `I,0x10` | **自动识别**（先 NFC，失败转扫码） |
| `C,addr` | `C,0x10` | 只触发扫码 |
| `N,addr` | `N,0x10` | 只触发 NFC |
| `R,addr` | `R,0x10` | 读取识别结果 |
| `Q,addr,res` | `Q,0x10,qr` | 读扫码持久缓冲区（`qr`）或 NFC 缓冲区（`nfc`） |
| `E,addr,deg` | `E,0x10,45` | 挡片转到指定角度（0~180） |
| `E,addr,up` | `E,0x10,up` | 挡片放行 |
| `E,addr,down` | `E,0x10,down` | 挡片阻挡 |
| `K,addr,on\|off` | `K,0x10,on` | 识别单元皮带启动 / 停止 |
| `K,addr,sec,N` | `K,0x10,sec,3` | 皮带运行 N 秒 |
| `K,addr,pwm,N` | `K,0x10,pwm,255` | 皮带速度 0~255 |
| `K,addr,dir,F\|R` | `K,0x10,dir,R` | 皮带方向 |
| `Q,addr,card` | `Q,0x10,card` | 读光敏 / 有卡状态 |
| `A,addr` | `A,0x10` | 自检（`@` 命令） |

#### 分拣单元（0x20 ~ 0x23）

| 命令 | 例子 | 作用 |
|---|---|---|
| `S,addr,raise` | `S,0x20,raise` | 两个舵机同时抬升 |
| `S,addr,lower` | `S,0x20,lower` | 两个舵机同时下降 |
| `S,addr,au` | `S,0x20,au` | A 舵机抬升 |
| `S,addr,ad` | `S,0x20,ad` | A 舵机下降 |
| `S,addr,bu` | `S,0x20,bu` | B 舵机抬升 |
| `S,addr,bd` | `S,0x20,bd` | B 舵机下降 |
| `S,addr,stop` | `S,0x20,stop` | 停止两个舵机 |
| `S,addr,hold` | `S,0x20,hold` | 抬手保持自动放下 |
| `S,addr,arm` | `S,0x20,arm` | 布防（有卡自动执行一次） |
| `S,addr,disarm` | `S,0x20,disarm` | 撤防 |
| `P,addr,act,ms` | `P,0x20,au,1000` | 设参数：`au`/`ad`/`bu`/`bd` = 时间(×10ms)；`spd` = 速度(×10µs) |
| `T,addr` | `T,0x20` | 读状态（限位 / 有卡 / 阶段 / 错误 / 抬升次数） |
| `L,addr,n` | `L,0x20,3` | 点亮 n 颗灯（测试用） |

## 三、Nano → PC 上报

### 3.1 格式约定

- 每行以 `[...]` 开头标明类型
- 字段用逗号分隔
- 每行以 `\r\n` 结尾

### 3.2 上报类型

| 类型 | 格式 | 说明 |
|---|---|---|
| **握手** | `[握手] NANO-READY V6.0` | 收到 `H` 后的回执 |
| **状态** | `[状态] 0x10=RUN,0x20=IDLE,0x21=IDLE,0x22=IDLE,0x23=IDLE` | `?` 的完整回执 |
| **识别成功** | `[识别] 1,QR,8,00121217` | 1=成功，类型，字节数，数据 |
| **识别成功** | `[识别] 1,NFC,7,048A425DBD2A81` | NFC UID |
| **识别失败** | `[识别] 0,0,0,-` | 0=失败 |
| **进料** | `[进料] 计数=5,电机=STOP,主机=ON` | 进料单元状态 |
| **光敏** | `[光敏] LDR=820,基准=2100,39%` | `Q,ldr` 回执 |
| **按钮** | `[按钮] D3` / `[按钮] D6` | 物理按钮事件 |
| **分拣** | `[分拣] 0x20=IDLE,抬升=12` | `T,addr` 回执 |
| **识别状态** | `[识别状态] 0x10=IDLE,CARD=0,BELT=STOP,GATE=90` | `?` 或 `Q,addr,card` 回执 |
| **事件** | `[事件] CARD,0x22` | 分拣单元检测到卡 |
| **错误** | `[错误] SCAN-TIMEOUT` | 错误码见 3.3 |
| **主机** | `[主机] 在线` / `[主机] 离线` | 保活状态变化 |
| **自检** | `[自检] 0x10=PASS` | `A,addr` 回执 |

### 3.3 错误码

| 错误码 | 含义 |
|---|---|
| `SCAN-TIMEOUT` | 扫码超时（0 字节） |
| `NFC-NOCARD` | NFC 未读到卡 |
| `I2C-NOACK` | 从机无应答 |
| `UNIT-NOTFOUND` | 地址不存在 |
| `PARAM-INVALID` | 参数错误 |

## 四、保活机制（沿用 V1.2）

```
PC 每 5 秒发送一次 H
Nano 收到任何串口数据 → 判定"主机在线"
超过 15 秒没收到任何数据 → 判定"主机离线"
```

**在线时：** 按钮只上报事件，不执行本地动作（防误触）  
**离线时：** 按钮恢复本地功能（D3=复位计数，D6=推一张卡）

## 五、典型交互流程

### 5.1 开机握手

```
PC  → H
Nano→ [握手] NANO-READY V6.0
Nano→ [主机] 在线
```

### 5.2 识别一张卡

```
PC  → I,0x10
Nano→ [识别] 1,NFC,7,048A425DBD2A81
```

### 5.3 识别一个二维码

```
PC  → C,0x10
Nano→ [识别] 1,QR,8,00121217
```

### 5.4 分拣动作

```
PC  → S,0x20,raise
Nano→ [分拣] 0x20=RUN

（等待到位）

PC  → S,0x20,lower
Nano→ [分拣] 0x20=IDLE
```

### 5.5 查询全部

```
PC  → ?
Nano→ [状态] 0x10=RUN,0x20=IDLE,0x21=IDLE,0x22=IDLE,0x23=IDLE
Nano→ [进料] 计数=5,电机=STOP,主机=ON
Nano→ [光敏] LDR=820,基准=2100,39%
```

### 5.6 进料一张

```
PC  → c
Nano→ [进料] 推卡中
Nano→ [按钮] D6          （如果用按钮触发）
Nano→ [进料] 计数=6,电机=STOP,主机=ON
```
