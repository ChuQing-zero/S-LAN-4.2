## 二、四颗指示灯的含义

| LED | 引脚 | 什么时候亮 |
|---|---|---|
| LED1 | **PB14** | **有卡**（光敏检测到遮挡） |
| LED2 | **PB15** | **识别中**（正在读码/读卡） |
| LED3 | **PA11** | **识别成功**（读到结果后亮约 0.25 秒） |
| LED4 | **PA12** | **通信活动**（I²C 收到命令时亮，1 秒无通信灭） |
| 电源灯 | 硬件 | 上电常亮 |

**都是纯通断，不会渐亮渐暗、不会自己闪。**

## 三、全部寄存器

### 3.1 参数区（写）

| 地址 | 名称 | 默认 | 说明 |
|---|---|---|---|
| `0x10` | BELT_PWM | 150 | 皮带速度 0~255 |
| `0x11` | BELT_DIR | 1 | 皮带方向 0/1 |
| `0x12` | IDENT_MODE | 0 | 0手动 1单次 2自动 3持续 |
| `0x13` | SCAN_TIMEOUT | 30 | 扫码超时 ×100ms = 3 秒 |
| `0x14` | NFC_TIMEOUT | 20 | NFC 超时 ×100ms = 2 秒 |
| `0x15` | PRIORITY | 0 | 0先NFC 1先扫码 2都做 |
| `0x16` | CARD_TH | 2000 | 有卡阈值（读回值 = 实际÷16） |
| `0x17` | BLOCK_MS | 30 | 遮挡判定 ×10ms |
| `0x18` | LED_TEST | 0 | 0=自动 非0=强制点亮 |
| `0x19` | GATE_REST_DEG | 90 | 挡片放行角度 |
| `0x1A` | GATE_BLOCK_DEG | 20 | 挡片挡住角度 |
| `0x1B` | GATE_MS | 30 | 挡片转动时间 ×10ms |

### 3.2 读回区（读）

| 地址 | 名称 | 说明 |
|---|---|---|
| `0x02` | STATUS | 状态位 |
| `0x03` | ERR | 错误码 |
| `0x04` | HB | 心跳（读一次+1） |
| `0x05` | FW | 版本 |
| `0x06` | TYPE | 1 = 识别单元 |
| `0x07` | ADDR | 0x10 |
| `0x20`/`0x21` | ADC_L/H | 光敏原始值 |
| `0x22` | CARD | 当前有卡 |
| `0x23` | RES_TYPE | 0无 1NFC 2二维码 3条码 |
| `0x24` | RES_LEN | 结果长度 |
| `0x25` | MSTATE | 0空闲 1等卡 2识别中 3有结果 4故障 |
| `0x26` | ERR | 错误码 |
| `0x27` | BELT_STATE | bit0=在转 |
| `0x28` | GATE_DEG | 挡片当前角度 |
| `0x40`~`0x5F` | RES_BUF | **结果缓冲区 32 字节** |

## 四、逐功能测试步骤

### 4.1 基础通信

```
o                     ← 应看到 0x10 在线
h 0x10                ← 连敲两次，HB 必须递增
```

期望：

```
0x10 IDENT  HB=5  FW=0x10  ADC=1295
```

| 检查项 | 判据 |
|---|---|
| 心跳 | 每次读 +1 |
| 版本 | `0x10` |
| 光敏 | ADC 在 200~4000 之间 |

---

### 4.2 光敏 + 有卡灯（LED1）

```
p 0x10
```

**然后用手挡住光敏电阻，再敲一次：**

```
p 0x10
```

| 情况 | ADC | CARD | LED1 |
|---|---|---|---|
| 有光 | 高 | 0 | 灭 |
| **遮住** | **低** | **1** | **亮** |

**判定：ADC < 阈值 且 持续 300ms → CARD=1。**

**如果方向反了**（遮住 ADC 变大），说明极性反，需要改固件 `CARD_ADC_HIGH`。

**如果一直不变**，先标定阈值：

```
没遮光：p 0x10 → 记 ADC_A
遮住：  p 0x10 → 记 ADC_B
取中间值 M = (ADC_A + ADC_B) / 2

- 0x10 M        ← 直接写阈值
```

---

### 4.3 挡片舵机（180° 位置舵机）

⚠️ **先测中间角度，别直接给极限值。**

```
g 0x10 45              ← 转到 45°
x 0x10                 ← 看 GATE 是否变 45
```

```
g 0x10 135             ← 转到 135°
x 0x10                 ← 看 GATE 是否变 135
```

**确认能自由行程后，再测两个端点：**

```
u 0x10                 ← 放行位（默认 90°）
d 0x10                 ← 挡住位（默认 20°）
g 0x10 0               ← 0°（看机构会不会顶死）
g 0x10 180             ← 180°（看机构会不会顶死）
```

**改角度不用重烧**：

```
写寄存器 0x19 = 放行角度
写寄存器 0x1A = 挡住角度
写寄存器 0x1B = 转动时间（×10ms）
```

---

### 4.4 皮带电机

⚠️ **电机 12V 电源必须接上。**

| 命令 | 动作 |
|---|---|
| `r 0x10` | 正转（一直转） |
| `t 0x10` | 停 |
| `# 0x10 3` | **转 3 秒自动停** |
| `v 0x10` | 方向取反 |

**调速**：

```
+ 0x10 150      ← 0~255，数值越大越快
```

**看状态**：

```
x 0x10          ← STATUS 的 bit6 表示在转
```

---

### 4.5 扫码（条形码 / 二维码）

**① 单独触发扫码**

```
c 0x10                ← 触发，最多等 3 秒
z 0x10                ← 读结果
```

**成功**：

```
RES_TYPE=3  RES_LEN=11
RES_BUF = [99999380111]
```

**失败**：

```
RES_TYPE=0  RES_LEN=0
(empty)
```

同时 `MSTATE=4`、`ERR=0x2`。

**② 改超时**

```
写寄存器 0x13 = 秒数×10     （30 = 3 秒）
```

---

### 4.6 NFC 读卡（PN532）

**① 单独读卡**

```
* 0x10                ← 触发 NFC，最多等 2 秒（NFC_TIMEOUT）
z 0x10                ← 读结果
```

**成功**：

```
RES_TYPE=1  RES_LEN=7
RES_BUF = [04 A2 2C 5A 1B 80 00]
```

`RES_TYPE=1` 表示 NFC，`RES_LEN` 一般是 4 或 7 字节 UID。

**失败**：

```
RES_TYPE=0  MACH=FAULT  ERR=0x2
```

**② 传感器使能/关闭**

```
= 0x10               ← SENSOR_ON
% 0x10               ← SENSOR_OFF
```

**③ PN532 接线必须正确**

| PN532 | MCU |
|---|---|
| SCK | PA5 |
| MISO | PA6 |
| MOSI | PA7 |
| SS / CS | PA4 |
| 供电 | **3.3V（不要 5V）** |
| GND | 共地 |

---

### 4.7 自动识别（先 NFC 后扫码）

```
a 0x10                ← 自动识别
z 0x10                ← 读结果
```

**逻辑**：按 `PRIORITY` 寄存器决定顺序

| PRIORITY | 行为 |
|---|---|
| `0` | 先 NFC，失败再扫码 |
| `1` | 先扫码，失败再 NFC |
| `2` | 两个都试 |

**改优先级**：

```
写寄存器 0x15 = 0/1/2
```

**判定**：拿 IC 卡贴上去 → 应返回 `RES_TYPE=1`；拿二维码扫 → 应返回 `RES_TYPE=3`。

---

### 4.8 自动模式（有卡就识别）

```
写寄存器 0x12 = 2      ← IDENT_MODE = 自动
```

然后**把卡放到光敏上**：

```
CARD=1 → 皮带自动停 → 自动识别 → LED2 亮（识别中）→ LED3 亮（成功）
```

---

### 4.9 持续模式（传感器一直使能）

```
写寄存器 0x12 = 3      ← IDENT_MODE = 持续
```

扫码模块一直使能，**读到就立即断电并上报**。

---

### 4.10 指示灯自测

```
l 0x10 1       ← 只亮 1 颗
l 0x10 2       ← 亮 2 颗
l 0x10 3
l 0x10 4       ← 亮 4 颗
y 0x10         ← 四颗全闪（强制模式）
```

---

### 4.11 全功能自检

```
@ 0x10
```

依次执行：挡片 90°→0°→90°→180°→90° → 4 灯轮流亮 → 皮带转 0.8 秒。

**一条命令验证所有执行器。**

---

### 4.12 复位

```
0 0x10
```

停皮带、挡片回放行位、清结果、关自动模式、清故障。

## 七、常见故障对照

| 现象 | 可能原因 | 怎么查 |
|---|---|---|
| 串口没横幅 | 没烧对文件 / 波特率错 | 看编译日志 `compiling` 的文件路径 |
| `o` 里没有 0x10 | 地址不对 / 没运行 | 上电看 PC13 闪不闪 |
| 心跳不涨 | I²C 读失败 | 量 A4/A5 电压是否 5V |
| 灯不亮 | LED 焊反 / 引脚 | `l 0x10 1` 单独点 |
| 光敏数值不变 | 光敏没接 / 分压电阻 | 量 PA0 电压 |
| 挡片不动 | 舵机没电 / 信号线 | 量 U2/U3 的 5V、PB11 有无 PWM |
| 皮带不动 | 12V 没接 / L298N | 量电机端电压 |
| 扫码超时 | 波特率不是 9600 / TX-RX 接反 | 查模块手册 |
| NFC 超时 | 3.3V 没供 / SPI 接错 | 量 PN532 供电、核对 PA4~PA7 |
| 结果读出来是乱码 | 波特率 / 编码 | 用 `z` 看十六进制 |
