# 识别单元（0x10）整体联调测试清单

> 固件：`31-IdentUnit-V5/main.c`  
> 主站：Nano（`28-NanoAllTest.ino`），I²C 100kHz → 现为 50kHz  
> 串口：H2 排针 115200（调试日志），CN1 9600（扫码模块）

## 一、上电自检（无卡无码）

**Nano 命令：**

```
o
```

**期望：**

```
0x10 IDENT  HB=x  FW=0x10  ADC=xxxx
```

**判定：**

- [ ] 0x10 能被扫描到
- [ ] HB 每次读取递增
- [ ] ADC 在 1000~3000 之间（光敏有响应）

---

## 二、光敏 + 有卡指示灯

**步骤：**

```
p 0x10          ← 不遮光，记 ADC 值 A
（手遮住光敏）
p 0x10          ← 遮光，记 ADC 值 B
```

| 记录 | 数值 |
|---|---|
| 不遮光 A | ______ |
| 遮光 B | ______ |

**设置阈值（取中间值）：**

```
- 0x10 <阈值>
```

例：A=1800、B=2900 → 阈值设 2350 → `- 0x10 2350`

**验证：**

```
x 0x10
```

- [ ] 不遮光时 `CARD=0`
- [ ] 遮光时 `CARD=1`
- [ ] 板上 PA11（LED3）随遮挡亮灭

---

## 三、挡片舵机（180° 位置舵机，PB11）

**逐项测试：**

```
u 0x10          ← 挡片放下（放行）
d 0x10          ← 挡片抬起（阻挡）
g 0x10 45       ← 转到 45°
g 0x10 90       ← 转到 90°
g 0x10 135      ← 转到 135°
```

**判定：**

- [ ] 挡片能到底（180°）不卡死
- [ ] 45/90/135 位置准确
- [ ] 回读 `x 0x10` 的 `GATE=xxdeg` 与实际一致
- [ ] 记录机械极限角：放行 ____° / 阻挡 ____°

**校准：**

```
- 0x10 0x19 <放行角度>
- 0x10 0x1A <阻挡角度>
```

---

## 四、皮带电机（PB0/PB1/PB10）

**逐项测试：**

```
+ 0x10 150      ← 设速度 150
r 0x10          ← 启动
x 0x10          ← 看 BELT_STATE
t 0x10          ← 停止
```

**方向：**

```
v 0x10          ← 反转
t 0x10          ← 停
```

**定时运行：**

```
# 0x10 3        ← 运行 3 秒自动停
```

**判定：**

- [ ] 正转方向正确（卡片往分拣方向走）
- [ ] 反转可用
- [ ] 速度 150/200/255 都能带动，不堵转
- [ ] `# 0x10 3` 3 秒后自动停
- [ ] 把速度设 255 试试是否更有力

---

## 五、扫码模块（CN1，9600）

**接线确认：**

```
模块 TX  →  CN1 脚4（PA3）
模块 RX  →  CN1 脚3（PA2）
模块 GND →  CN1 脚2
模块 VCC →  CN1 脚5（3.3V）
```

**测试：**

```
c 0x10
（立刻拿二维码对着扫）
z 0x10
```

**期望：**

```
RES_TYPE=3  RES_LEN=11
RES_BUF = [条码内容]
```

**判定：**

- [ ] 能读到码
- [ ] RES_LEN 与条码长度一致
- [ ] 多次扫描结果稳定一致

---

## 六、NFC 模块（PN532，SPI1）

**接线确认（6 根）：**

```
SS=PA4  SCK=PA5  MISO=PA6  MOSI=PA7  VCC=3.3V  GND
```

**测试：**

```
* 0x10
（IC 卡贴天线 2~3cm）
z 0x10
```

**期望：**

```
RES_TYPE=1  RES_LEN=7
RES_BUF = [04 8A 42 5D BD 2A 81]
```

（你那张卡的实际 UID：`04 8A 42 5D BD 2A 81`）

**判定：**

- [ ] RES_TYPE=1（NFC，不是扫码）
- [ ] UID 与 12 号测试读到的一致
- [ ] 连续读 5 次结果相同

---

## 七、自动识别（完整流水线）

**这是识别单元的核心功能。**

```
a 0x10
z 0x10
```

**逻辑：** 先试 NFC → 失败再试扫码

| 测试 | 操作 | 期望 |
|---|---|---|
| IC 卡 | 贴卡 | `RES_TYPE=1` |
| 二维码 | 拿码对着扫 | `RES_TYPE=3` |
| 都没有 | 空手 | `RES_TYPE=0  RES_LEN=0` |

**判定：**

- [ ] 贴 IC 卡 → 返回 NFC 类型
- [ ] 扫二维码 → 返回扫码类型
- [ ] 连续 10 次不卡死、不超时异常

## 九、完整状态读取

```
x 0x10
```

**应包含：**

```

```

**判定：**

- [ ] ERR = 0（无错误）
- [ ] 各项与实际硬件状态一致
