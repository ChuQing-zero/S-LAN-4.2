# 指示灯点名测试（每颗闪自己的编号）

S-LAN V4.0 / **STM32F103C8T6 蓝 pill**
纯寄存器 · 不用 CubeMX · 不用 HAL
日期：2026-09-22

> **一句话**：4 颗受程序控制的指示灯**一颗一颗点名**，每颗闪**自己的编号**次数。
>
> ```
>   灯1 (PB14) ── 闪 1 下
>   灯2 (PB15) ── 闪 2 下
>   灯3 (PA11) ── 闪 3 下
>   灯4 (PA12) ── 闪 4 下
>   两颗灯之间有约 0.8 秒全灭的间隔，一轮约 8 秒，然后循环
> ```
>
> **不接开关、不接光敏、不接 I²C。** 只验灯和线。
>
> ⭐ 灯 1 在 **PB14** —— 和 `01-单元板方案.md` §5.6 的 PCB 分配**完全一致**。

## 为什么不用"流水灯"

普通流水灯（1→2→3→4→全亮→全灭）**看不准**：

- 中间那个"全亮"步会让**好灯的也亮两次**，和"自己那一步"混在一起，看着像"闪两下"
- 几颗灯同时暗着的时候，**分不清哪颗是哪颗**

**换成"闪编号"就没有歧义**：闪 3 下的那一颗，**一定**是 PA11 那根线 ——
不管它物理上被你插到哪个位置。

| 你看到的 | 结论 |
|---|---|
| **一颗灯从来不闪** | 那颗 LED、那个 470Ω、或那 2 根线有问题 |
| **闪的次数和串口报的对不上** | **线插错针了**（比如插到 A12 上了，却以为插的是 B14）|
| **4 颗都闪对** | 4 颗灯 + 8 根线 + 两个 GPIO 端口全部没问题 |

## 一、4 颗灯分别是哪 4 颗

| 编号 | 闪烁次数 | 引脚 | 脚号 | 右排位置 | 含义 |
|---|---|---|---|---|---|
| **1** | **闪 1 下** | **PB14** | 27 | 从下往上第 3 根 | 限位 1 灯 |
| **2** | **闪 2 下** | **PB15** | 28 | 从下往上第 4 根 | 限位 2 灯 |
| **3** | **闪 3 下** | **PA11** | 32 | A9 上面第 1 根 | 卡牌检测灯 |
| **4** | **闪 4 下** | **PA12** | 33 | A9 上面第 2 根 | 通信灯 |

> ```
>       A12   ← 灯 4（闪 4 下）
>       A11   ← 灯 3（闪 3 下）
>       A10   串口
>       A9    串口
>       A8    ✂ 空着
>       B15   ← 灯 2（闪 2 下）
>       B14   ← 灯 1（闪 1 下）
>       B13
>       B12
> ```

### ⭐ 记住这个坑：灯不亮，先查接触

搭板初期 **PB14 接的那颗灯不亮**（同时 PB15 亮 —— 这两个脚是**同一条指令**
写进去的，所以代码没问题）。当时怀疑引脚坏了，把灯 1 挪到 PA8 去绕。

**后来发现：是板子/线没插紧。**

| 教训 | |
|---|---|
| **板子没插紧 / 杜邦线松** | 会伪装成"引脚坏了""灯坏了""程序错了"，全都长得像 |
| **一次动一样东西** | 当时同时怀疑了灯、电阻、引脚、代码，其实只要先拔出来重插一次 |
| **5 秒 vs 5 分钟** | 重插的成本是 5 秒，换一颗灯是 5 分钟，改代码是 30 分钟 |

### ⚠️ 第 5 颗灯不参与点名

**电源灯**直接挂 +3V3（串 470Ω），**上电就常亮，永远不闪**。**这是对的，不是故障。**

反过来它有用：**电源灯要是灭的，说明 3.3V 根本没上来**，别的灯也不可能亮。

## 二、接线（4 颗灯，8 根线）

**4 颗接法完全一样**，只是引脚不同：

```
   PB14 ──[ 470Ω ]── LED1 长脚（正极）
                      LED1 短脚（负极）──> GND

   PB15 ──[ 470Ω ]── LED2 长脚          LED2 短脚 ──> GND

   PA11 ──[ 470Ω ]── LED3 长脚          LED3 短脚 ──> GND

   PA12 ──[ 470Ω ]── LED4 长脚          LED4 短脚 ──> GND
```

> **电阻夹在「引脚」和「LED 长脚」之间**，LED 短脚去 GND。
> **长脚 = 阳极（正极）**，也可以看灯珠内的小方块，**小的一边是正极**。
> 接反了不亮也不烧（才 3mA），掉个头就行。

### 串口（可选，但建议接）

```
   CH340 TXD ──> PA10        RXD ──> PA9        GND ──> GND        VCC 不接
```

接上串口后，**每颗灯闪之前串口会先报出它的名字**，边看串口边看灯，最准。

### ⚠️ 电阻别用错

| 用什么 | 电流 | 效果 |
|---|---|---|
| **470Ω** ✅ | 约 2.5–3 mA | 就按这个做 |
| 220Ω ✅ | 约 5 mA | 更亮，也能用 |
| 1kΩ ❌ | 约 1.3 mA | **暗到看不出来** |

LED 用**红 / 绿 / 黄**。蓝、白的 Vf ≈ 3.2V，**3.3V 供电根本点不亮**。

## 四、应该看到什么

```
① 上电：板载小灯（PC13）慢闪 3 下          = 程序在跑

② 然后开始点名，一轮约 8 秒：

     全灭 0.8 秒
     灯1 闪 1 下          ← 只有它亮，其他三颗和电源灯之外全灭
     全灭 0.8 秒
     灯2 闪 2 下
     全灭 0.8 秒
     灯3 闪 3 下
     全灭 0.8 秒
     灯4 闪 4 下
     全灭 1.5 秒          ← 一轮结束，板载小灯翻一次

③ 串口同步刷出：
     -- round 1 --
       (all off)
       [1] PB14  limit switch 1 lamp   x1
       (all off)
       [2] PB15  limit switch 2 lamp   x2
       (all off)
       [3] PA11  card detect lamp      x3
       (all off)
       [4] PA12  comm lamp             x4
       (all off)
```

## 五、⭐ 怎么看结果

**盯着看一轮，把每颗灯实际闪了几下记下来：**

| 灯 | 应该闪 | 实际闪 |
|---|---|---|
| 灯1（PB14）| 1 下 | ______ |
| 灯2（PB15）| 2 下 | ______ |
| 灯3（PA11）| 3 下 | ______ |
| 灯4（PA12）| 4 下 | ______ |

### 判读

| 现象 | 结论 |
|---|---|
| **4 颗都闪对** ✅ | 灯和线全好，可以进下一步 |
| **某颗从来不闪** | 那颗 LED / 那个电阻 / 那 2 根线的问题 → 看下面 |
| **闪的次数和上表对不上**（比如以为接的是灯1，结果它闪 4 下）| **线插错针了** —— 它其实接在 PA12 上 |
| **只有一颗亮，其余全灭** | 那一颗的灯和线是好的，另外 3 颗的线/灯有问题 |
| **四颗交替乱闪、或者该灭的时候灭不掉** | 灯的**负极接错地方了**（接到了别的引脚而不是 GND）|
| **电源灯不亮** | 3.3V 没上来，先查供电 |

### ⭐ 定位"某颗不闪"最快的办法：**搬灯**

把**好的那颗灯**（A12 上那颗）的**「引脚那根线」**从 A12 拔下来，插到不闪的那根针上
（电阻、LED、接地线都不动）。然后看那一颗该闪的时候：

| 现象 | 结论 |
|---|---|
| **换过去就亮了** ✅ | **那根针和程序都没问题** → 是你原来接在它上面的**灯或电阻坏了**，或者**根本没接灯** |
| **换过去还是不亮** | **那根针有问题** —— 插错针了，或者那根针没插实 |

### 按这个顺序查（从最常见的开始）

| # | 查什么 | 怎么查 |
|---|---|---|
| 1 | **电阻和 LED 插在面包板的同一排** | 同一排 5 个孔是**连通的** → 被短路 → 不亮。**两脚必须跨在不同排** |
| 2 | **LED 长脚短脚接反** | 掉个头 |
| 3 | **负极没真接到 GND** | 从好灯的负极位置拉一根线过去试 |
| 4 | **跨了面包板中间的沟** | 中间那条沟**左右不通**，跨沟等于断路 |
| 5 | **引脚认错** | 右排从下往上：B12、B13、B14、B15；A8、A9、A10 再往上，A11/A12 在更上面 |
| 6 | **灯是蓝 / 白的** | 3.3V 点不亮 → 换红/绿/黄 |
| 7 | **用了 1kΩ** | 太暗，看着像不亮 → 换 470Ω |
| 8 | **就一颗不亮，其他都对** | 基本就是那一颗的 **LED 或电阻坏了** |

## 六、串口没输出怎么办

| 现象 | 原因 |
|---|---|
| **一个字都没有** | ① **TXD/RXD 接反了**（最常见）② CH340 的 GND 没接 ③ 波特率不是 115200 |
| **全是乱码** | ① 波特率不对 ② 看开机那行是不是 `NOT PLL` —— 晶振没起振 |
| **串口里是 `limit switch + indicator LED test`** | ❌ 烧错程序了，那是 06，重新烧 07 |

**没有串口也能用** —— 直接数灯闪的次数就行，这正是这个版本的设计目的。
