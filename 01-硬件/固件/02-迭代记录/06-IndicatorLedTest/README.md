# 限位开关 + 外接指示灯测试

S-LAN V4.0 / **STM32F103C8T6 蓝 pill**
纯寄存器 · 不用 CubeMX · 不用 HAL
日期：2026-09-22

> **这是面包板计划【阶段 2】的最后一项** —— 前面 `04-LimitSwitchTest` 只验了
> "能不能读到限位开关"，这一步验的是 **"能不能驱动 PCB 上真正要用的那两颗灯"**。
>
> ```
>   限位开关 1（PB9）  ──>  指示灯 1（PB14）
>   限位开关 2（PB5）  ──>  指示灯 2（PB15）
>
>   板载小灯（PC13）  ──>  1 秒闪一次的"心跳"，证明程序还活着
> ```
>
> 开关状态同时从**串口打印出来**，方便对照灯和开关是不是一致的。

---

## 一、为什么单独做这一步

`04` 用的是**板载**那颗小灯（PC13）。但 PCB 上真正的指示灯是 **PB14 / PB15** 两颗外接灯。

这一步就是**把 PCB 上的那两个位置提前在面包板上搭出来**：

| 验证什么 | 为什么值得单独验 |
|---|---|
| PB14 / PB15 能驱动外接 LED | PCB 上就是这两个脚 |
| **470Ω 限流够不够亮** | 选错了 PCB 上就是一片暗灯，改不了 |
| 外接灯的**极性**（高电平亮）| 和板载 PC13 **正好相反**，极易搞混 |
| 470Ω + LED + GND 的**实际接法** | 照抄到 PCB 就行 |

> ⚠️ **这一步比 04 多一个坑：两个灯的极性是反的。**
>
> | 灯 | 接法 | 点亮条件 |
> |---|---|---|
> | **PB14 / PB15**（外接）| 引脚 → 470Ω → LED正极，LED负极 → GND | **高电平亮** |
> | **PC13**（板载）| 板子内部：3.3V → LED → 引脚 | **低电平亮** |

## 二、接线（11 根线）

### ① 两个限位开关（4 根）

```
   限位开关 1
   ┌────────┐
   │ COM ●──┼──────────────>  PB9    ← 右排丝印 "B9"（脚 46）
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘

   限位开关 2
   ┌────────┐
   │ COM ●──┼──────────────>  PB5    ← 右排丝印 "B5"（脚 41）
   │ NC  ●──┼──────────────>  GND
   │ NO  ●──┼────── ✂ 空着不接
   └────────┘
```

> ⚠️ **两根针都在右排上半部分**（B9 从上数第 4 根，B5 第 8 根），
> 不再是以前的 PB12 / PB13（右排最底下）。
>
> ⚠️ **PB5 不 5V 耐受**（脚 41），别往它上面接 5V。

### ② 两颗指示灯（4 根）

```
   PB14 ──[ 470Ω ]── LED1 长脚（正极 ─ 阳极）
                      LED1 短脚（负极 ─ 阴极）──> GND

   PB15 ──[ 470Ω ]── LED2 长脚
                      LED2 短脚 ──> GND
```

> ⭐ **长脚是正极，接电阻那一头。短脚接地。**
> 接反了灯**不会亮，也不会烧**（3mA 而已），掉个头就行。

### ③ 串口（3 根）

```
   CH340 TXD ──> PA10      （STM32 的 RX）
   CH340 RXD ──> PA9       （STM32 的 TX）
   CH340 GND ──> GND
   CH340 VCC ──> ✂ 不接
```

### ⚠️ 电阻别选错

| 用什么 | 电流 | 效果 |
|---|---|---|
| **470Ω** ✅ | 约 2.5–3 mA | 够亮，就按这个做 |
| 220Ω ✅ | 约 5 mA | 更亮，也能用 |
| 1kΩ ❌ | 约 1.3 mA | **暗到看不出来，别用** |

**LED 用红 / 绿 / 黄** —— 蓝、白 LED 的 Vf ≈ 3.2V，3.3V 供电基本点不亮。

## 三、引脚位置

```
   蓝pill 右排（从上往下）：

       3V3
       GND
       5V
       B9
       B8
       B7
       B6
       B5
       B4
       B3
       A15
       A12
       A11
       A10        ← 串口 CH340 TXD 接这里
       A9         ← 串口 CH340 RXD 接这里
       A8
       B15  ┐ ← 指示灯 2（限位 2）
       B14  │ ← 指示灯 1（限位 1）
       B13  │ ← 限位开关 2 的 COM
       B12  ┘ ← 限位开关 1 的 COM（最角落那一个）
```

> ⭐ **最下面四根针全在这里**，从下往上依次是：**B12 → B13 → B14 → B15**。
> 一根线都不用挪地方，限位和指示灯挨着。

> 串口的 PA9 / PA10 就在 **A8 上面两根**，离得也近。

> 面包板的 **GND 轨**要拉 4 根线出去：两个开关的 NC、两颗灯的短脚。

## 四、Keil 里怎么用

```
① 在 06-IndicatorLedTest 文件夹里新建 Keil 工程
   （和 03 / 04 / 05 完全一样的做法）

② Project → Manage → Run-Time Environment
        [x] CMSIS  → CORE
        [x] Device → Startup

③ 把本文件夹的 main.c 整份替换掉工程里的 main.c

④ Options for Target → Device 标签页
        还是选 STM32F103C6，别改

   Options for Target → Debug 标签页
        → 下拉选 【ST-Link Debugger】

   Options for Target → Flash Download 标签页
        → ⭐ Programming Algorithm 列表不能是空的
          空的就 【Add】→ 【STM32F10x 128KB Flash】→ Add → Close
        → 勾 【Reset and Run】
        → 勾 【Erase Full Chip】

⑤ F7 编译  →  F8 下载
```

> **不用勾 `Use MicroLIB`** —— 这个程序没用到 printf。
>
> ⚠️ 用老器件包时**必须** `#include "stm32f10x.h"`（不是 `stm32f1xx.h`），
> 而且前面要先定义密度宏 —— main.c 里已经自动处理了。

## 五、应该看到什么

```
① 上电 / 按复位
     板载小灯（PC13）慢闪 3 下        = 程序在跑

② 串口立刻出现
     =====================================================
       S-LAN V4.0   limit switch + indicator LED test
       SW1=PB9   SW2=PB5    LED1=PB14  LED2=PB15
       PC13 onboard LED = 1 Hz heartbeat
       clock: PLL, 72 MHz - good
     =====================================================

③ 之后每 200ms 刷一行：
     SW1=0  SW2=0   N1=  0  N2=  0   both switches open
```

**然后动手按：**

| 操作 | 指示灯 1（PB14）| 指示灯 2（PB15）| 串口 |
|---|---|---|---|
| 都不按 | 灭 | 灭 | `SW1=0 SW2=0  both switches open` |
| **按住开关 1** | **亮** ✅ | 灭 | `SW1=1 SW2=0  switch 1 triggered` |
| **按住开关 2** | 灭 | **亮** ✅ | `SW1=0 SW2=1  switch 2 triggered` |
| **两个一起按** | **亮** | **亮** | `SW1=1 SW2=1  BOTH switches triggered` |
| 松开 | 灭 | 灭 | 回到全 0 |

**板载小灯（PC13）在旁边 1 秒闪一次** —— 这是心跳，和两个指示灯没关系，别搞混。

## 六、⭐ 按 20 次验一下

```
   按开关 1 二十次  →  N1 应该正好是 20
   按开关 2 二十次  →  N2 应该正好是 20
```

| 结果 | 意思 |
|---|---|
| **N1 = 20** ✅ | 完美，没有抖动误计数 |
| N1 = 25 或 30 | **触点抖动**（机械开关正常现象），但 200ms 轮询已经滤掉了，出现这个说明开关质量差 |
| N1 = 20 但灯偶尔闪 | 线接触不良 |

> 程序是 **200ms 轮询一次**，机械抖动只有几毫秒，所以天生就被滤掉了，
> 不需要额外的消抖代码。**N1/N2 就是这个方案没加消抖也能用的证据** —— 论文里可以写。

### ⭐ 再验一次"断线保护"

**把开关的 NC 那根线从面包板上拔掉** →

```
   指示灯会常亮，串口变成 SW1=1
```

这是设计要的效果：**线断了 = 当成"已触发" = 安全停机**，而不是继续冲撞机构。

## 七、排查

| 现象 | 原因 |
|---|---|
| **上电没有慢闪 3 下** | 程序没跑 → 按复位键 / 查 BOOT0 / 勾 `Reset and Run` / Flash 算法没加 |
| **两个指示灯都不亮，但串口正常** | ① **LED 长脚短脚接反了**（掉个头）② 470Ω 忘了接 ③ 灯没接到 GND |
| **不按开关灯就常亮** | ① **NC 那根没接到 GND** ② 开关认错脚了，接到了 NO |
| **按开关灯不亮，但串口 SW1 变了** | **PB14 认错针了** → 最下面四根：B12、B13、B14、B15 从下往上 |
| **串口正常但灯全灭** | 灯的线插错排了 —— B14/B15 在**右排**，别插到左排去 |
| **灯很暗** | 用了 1kΩ，换成 **470Ω**；或者用了蓝/白 LED |
| **串口一个字都没有** | ① **TXD/RXD 接反** ② CH340 的 GND 没接 ③ 波特率不是 115200 |
| **串口全是乱码** | 看开机那行是不是 `NOT PLL` —— 晶振没起振 |

## 八、和 04 有什么区别

| | `04-LimitSwitchTest/` | `06-IndicatorLedTest/`（本文件夹）|
|---|---|---|
| 干什么 | **找针工具** | **正式程序** |
| 指示灯 | 板载 PC13，用**闪烁次数**报告 | 外接 PB14 / PB15，**一灯对一个开关** |
| 串口 | 没有 | **有**，直接打印电平 |
| 极性 | 低电平亮 | **高电平亮** |
| 用在哪 | 引脚下没接好时用来定位 | **PCB 上就是这个配置** |

**04 的使命已经完成了**（你已经把针找出来了）。以后就用 06。
