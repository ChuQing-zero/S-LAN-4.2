## 四颗指示灯（**自动驱动，PC 不用管**）

| LED | 引脚 | 什么时候亮 |
|---|---|---|
| LED1 | **PB14** | **限位1（CN2）按下** |
| LED2 | **PB15** | **限位2（CN3）按下** |
| LED5 | **PA11** | **光敏检测到卡牌** |
| LED3 | **PA12** | **I²C 收到命令时闪 50ms** |
| LED6 | 硬件 | 电源灯常亮 |

> 写 `LED_TEST`（`0x18`）可临时强制点亮查线，bit0~3 对应 4 颗灯；写 0 恢复自动。

## 寄存器表

### 参数区（写）

| 地址 | 名称 | 默认 | 说明 |
|---|---|---|---|
| `0x10` | SERVO_A_TIME | 100 | 舵机A 抬升时长（×10ms = 1.0 秒） |
| `0x11` | SERVO_B_TIME | 50 | 舵机B 抬升时长（×10ms = 0.5 秒） |
| `0x12` | SERVO_SPD | 50 | 转速偏移（×10µs，50 = 500µs） |
| `0x13` | HOLD_MS | 100 | 抬升后保持（×10ms） |
| `0x14` | **LOWER_MODE** | 0 | **0=两路同时 1=只降A 2=只降B** |
| `0x15` | LOW_TIMEOUT | 30 | 归位超时（×100ms = 3 秒） |
| `0x16` | CARD_TH | 2000 | 有卡 ADC 阈值 |
| `0x17` | BLOCK_MS | 30 | 光敏持续遮挡判定（×10ms） |
| `0x18` | LED_TEST | 0 | 0=灯自动；非0=强制点亮 |

### 读回区（读）

| 地址 | 名称 | 说明 |
|---|---|---|
| `0x04` | HB | 心跳，读一次 +1 |
| `0x05` | FW | 版本 |
| `0x06` | TYPE | 2 = 分拣单元 |
| `0x20`/`0x21` | ADC_L/H | 光敏原始值 |
| `0x22` | LIMIT_BITS | bit0 限位1、bit1 限位2（实时） |
| `0x23` | CARD | **当前有卡**（实时） |
| `0x24` | **CARD_LATCH** | **来过卡就锁存**，PC 慢也不漏 |
| `0x25` | LIFT_CNT | 完成次数 |
| `0x26` | PHASE | 0空闲 1抬升 2保持 3归位 4故障 |
| `0x27` | SERVO_STATE | bit0 A转、bit1 B转 |
| `0x28` | CLR | 写 `0xA5` 清锁存+计数+故障 |

### STATUS 位（`0x02`）

| 位 | 含义 |
|---|---|
| bit0 READY | 空闲 |
| bit1 BUSY | 动作中 |
| bit2 CARD | 光敏有卡 |
| bit3 LIM1 | 限位1 闭合 |
| bit4 LIM2 | 限位2 闭合 |
| bit5 FAULT | 故障 |
| bit6 LIFTED | 抬升/保持中 |
| bit7 PWM_OFF | 舵机已停 |

## 指令集（写 `0x00`）

| CMD | 名称 | ARG | 行为 |
|---|---|---|---|
| `0x01` | RESET | — | 停转、清故障、灯回自动 |
| `0x03` | STOP | — | 急停 |

| `0x12` | **LOWER** | — | 按 LOWER_MODE 下降，限位闭环 |
| `0x13` | SERVO_A_UP | — | 只动 A 抬升 |
| `0x14` | SERVO_A_DOWN | — | 只动 A 下降（限位A 管） |
| `0x15` | SERVO_B_UP | — | 只动 B 抬升 |
| `0x16` | SERVO_B_DOWN | — | 只动 B 下降（限位B 管） |
| `0x17` | SERVO_STOP | `0`/`1`/`2` | 全停 / 停A / 停B |
| `0x20` | LED_SET | mask | 强制点灯（bit0~3） |
| `0x21` | LED_CHASE | — | 流水灯，走完恢复自动 |
| `0x30` | SELFTEST | — | 全功能自检 |

## 方向约定（写死，不做参数）

舵机镜像安装，所以：

```
抬升：A 正转、B 反转
下降：A 反转、B 正转
```

PC 只需要说"抬升"或"下降"，不用管方向。

**高度差靠时长不同**：`SERVO_A_TIME` 长 → A 抬得高。

---

## 本地闭环（永不依赖 PC）

```
下降阶段：
    两路（或按 LOWER_MODE 单路）反向
    ├─ 限位A(PB5) 闭合  → 立刻停 A（微秒级）
    ├─ 限位B(PB9) 闭合  → 立刻停 B
    └─ 超过 3 秒        → ERR=0x01、FAULT
    全部到位 → 关 PWM（断电自锁）→ 计数+1 → READY
```

## 上机测试顺序

**① 单路方向**
```
1 0x20     舵机A 抬升
2 0x20     舵机A 下降
3 0x20     舵机B 抬升
4 0x20     舵机B 下降
```

**② 限位 + 灯**
手动按限位开关，看 LED1/LED2 亮不亮，配合 `i 0x20` 读状态。

**③ 一键分拣**
```
f 0x20
```
抬升 → 保持 → 自动下降 → 计数 +1。

**④ 单路下降**
```
先写 LOWER_MODE=1（只降A）→ 再发 0x12 LOWER
```
